# showcase-ru-en — личная память

## Витрина (README.md / README.ru.md)
- Сторож обеих версий — `.orchestra/tasks/511/check_table.py`, гонять после ЛЮБОЙ правки таблицы.
  Он проверяет: по одному статусу ✅/🚧/🚫 в строке, что по каждому `файл:строка` реально лежит
  названный в строке символ (±2 строки), одинаковый набор якорей в EN и RU, переключатель языка в
  обе стороны, порог размера `CLAUDE.md`.
- Статусную таблицу он отбирает по СЕКЦИИ (всё до первого `###`), а не по числу колонок: таблица
  сравнения с Orca тоже трёхколоночная, и отбор по колонкам красил её строки как «нет статуса».
- Правишь EN — правь RU тем же заходом. Расхождение якорей ловит пункт 7 сторожа.

## Проверка ссылок и бейджей с этого VPS
- GitHub отдаёт анонимному curl **404 на `/stargazers` и 429 на `/commits/main` для ЛЮБОГО**
  репозитория, включая чужие. Это блок анонимного HTML, а не мёртвая ссылка. Прежде чем писать
  «ссылка битая», прогони положительный контроль на заведомо живом чужом репозитории и проверь
  ресурс через `gh api` (`repos/<o>/<r>/commits/main`).
- Что бейдж реально РИСУЕТ, видно только запросом: `curl -sS <url> | grep -o '<title>[^<]*</title>'`.
  Так поймался `license: not identifiable by github` — картинка отдавала `http=200` и выглядела
  живой.
- Определение лицензии у GitHub читается с ИХ копии файла: `gh api repos/<o>/<r>/contents/LICENSE
  -q .size` против локального `wc -c`. Локальная починка `LICENSE` на `.license.key` не влияет,
  пока коммит не запушен.
