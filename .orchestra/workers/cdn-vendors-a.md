# cdn-vendors-a — личная память

## Как доставать доки вендоров, когда сайт не отдаёт текст (проверено 20.08.2026, #192)

Порядок, снизу вверх по цене. Останавливаться на первой сработавшей ступени:

1. **`<url>/llms-full.txt` и `llms.txt`** — сначала пробовать ЭТО. Timeweb отдаёт весь раздел
   документации CDN одним UTF-8 файлом (`timeweb.cloud/docs/cdn/llms-full.txt`, 60 КБ, 15 статей,
   с датой последнего обновления в шапке). Один `curl` вместо десятка рендеров.
2. **`<host>/sitemap.xml`** — когда навигация на JS и ссылок в HTML нет. Так нашлись рабочий
   адрес Beget CDN (`/ru/cloud/cdn`; заданный в тикете `/ru/cdn` = 404) и все 41 страница
   раздела CDN Selectel вместе с их настоящим префиксом `/cdn/`, а не `/networks-services/cdn/`.
3. **Исходники доков на GitHub.** `github.com/yandex-cloud/docs` — тот же текст, что на сайте,
   и он НЕ за капчей. `git clone --depth 1 --filter=blob:none --sparse` + `sparse-checkout set
   ru/cdn ru/_includes/cdn`. Внимание: `{% include %}` вытаскивают текст из `_includes/`,
   без этого каталога в ключевых местах будут дыры (так пряталась фраза про POST у Yandex).
4. **Playwright** — только для аккордеонов и калькуляторов (цены Selectel, ответы FAQ VK
   закрыты `.ui-toolkit-collapse-header`, кликать каждый). Бинарь ставится
   `python3 -m playwright install chromium`, ~110 МБ, ~1 мин.
5. **r.jina.ai** — когда curl отдаёт JS-оболочку. Против **Yandex SmartCaptcha не помогает**,
   как и headless-браузер: страница цен Yandex Cloud и `/ru/api/price-list` закрыты капчей
   наглухо. Это законный ответ «не выяснено», а не повод оценивать самому.

## Ловушка: гомоглифы при письме кириллицей

Написал в артефакт `грep` — «гр» кириллицей, «ep» латиницей (0x433 0x440 0x65 0x70).
`Edit` не находит строку, `grep "греп"` не находит, `str.replace` молча делает 0 замен —
и всё это выглядит как «правка не применилась». Диагностика в одну команду:
`print([hex(ord(c)) for c in seg])`. Чинить точным `replace` по выясненной паре, а не наугад.

## Правило про негативные утверждения (пригодилось трижды за задачу)

«В доках про X не сказано» — это утверждение, которое обязано иметь положительный контроль
В ТОЙ ЖЕ команде: `grep -c` по заведомо присутствующему слову плюс `file` (текстовый ли).
Пустой греп по битому/пустому файлу неотличим от честного нуля и врёт в ту же сторону,
что и ошибка. У Selectel контролем послужило слово «Таймаут», у Timeweb — «CDN» (155 хитов),
у Yandex — сам WebSocket, который греп находит, а SSE рядом с ним не находит.
