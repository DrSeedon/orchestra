# fix-initial-delivery-class

- Для исхода внешней доставки фиксировать структурную фазу у прямого callsite; RED-оракул должен
  бросать одинаковые тип и текст исключения до и после side effect, чтобы исключить классификацию
  по сообщению ошибки.
- Медленный `connect()` может завершиться после конкурентного `disconnect()`: проверять generation /
  identity кандидата и не возвращать изменяемое owner-поле как результат завершившейся операции.
- Исчерпывающий mapping persisted-state обязан иметь безопасный non-retryable fallback для старых
  неизвестных значений; проверять status + matching receipt, ноль wake и побайтово неизменную строку.
