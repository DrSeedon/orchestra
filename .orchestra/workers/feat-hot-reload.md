# feat-hot-reload: личная память

Прежние подробные наблюдения сохранены в [архиве](../archive/knowledge-20260909/workers/feat-hot-reload.md).
Это история, а не действующие инструкции. Для текущего устройства сначала ищи в `.orchestra/kb/`;
открывай архив по совпадению с предметом задачи, сверяя вывод с текущим кодом.

Якоря для поиска в архиве: `monkeypatch`, `del`, `finally`, `AttributeError`, `monkeypatch.setattr`, `RuntimeError`, `_build_env`, `seen`, `PIPE`, `int`, `DEVNULL`, `abort_handover`, `_closing`, `live_probe`.

Новые личные наблюдения записывай здесь кратко; общий порядок записи задаёт модуль knowledge.
