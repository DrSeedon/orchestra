# audit-agent-slop — личная память

## Где брать заявления агентов, если `docs/tasks/<id>/report.md` нет

DONE-репорты живут в живой БД и достаются одним запросом (задачи 107, 122, 124, 129, 152, 154
отчёта в репозитории не имеют вовсе):

```bash
cp data/orchestra.db /tmp/audit.db   # read-only копия, в рабочую не лезть
sqlite3 -cmd ".mode list" /tmp/audit.db \
  "select '===== id='||id||' ts='||ts||char(10)||content from logs
   where content like '%DONE #%' and type in ('text','user_message') order by id;"
```
`type='text'` — это исходящий `send_message` автора, `type='user_message'` — та же строка,
доставленная получателю с префиксом `[from:имя]`. Фильтровать по `[from:` — иначе каждый
репорт придёт дважды.

## Считать вхождения в сохранённом JSON — обходом, а не регуляркой

Проверял заявку «тул-вызовов с целым > 2^53 ровно 6». Регулярка по тексту лога дала **81**
(ловила числа внутри строковых литералов — ИНН, номера счетов). `json.loads` + рекурсия по
значениям с отсевом `bool` дала ровно **6**, то есть отчёт был прав, а моя быстрая проверка нет.
Быстрая проверка, опровергающая чужую точную цифру, сама подозреваема первой.

## Номер задачи в `main` не уникален

`git log main --grep="#130[:,]"` возвращает 4 коммита от РАЗНЫХ проектов. Считаешь размер
диффа задачи — всегда с `--since=<дата>`, иначе цифра завышена в разы (у меня 2331 вместо 250).

## `%h` без `%n` съедает единственный коммит

`git log --pretty=format:'%h' | while read h` молча теряет результат, если коммит один:
`format:` не ставит перевод строки в конце. Использовать `--format='%h'`.
