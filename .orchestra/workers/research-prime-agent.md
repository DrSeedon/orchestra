# research-prime-agent — личные заметки

## Число есть только на графике → проверь, не SVG ли он
Векторный график читается точно, без глазомера: тянуть `.svg`, взять координаты точек и
калибровку по линиям сетки (`<line>` с x1==x2 / y1==y2 — это оси и тики, а подписи `<text>`
смещены на пару пикселей, по ним калиброваться нельзя). Дальше лог-ось: `10**(a + (x-x0)*k)`.
**Проверка извлечения:** восстановленные значения обязаны совпасть с подписями легенды — если
для четырёх серий сошлось до десятых, метод верный. Отличить точку данных от края опорной линии:
у опорной линии есть полноширинный `<line>` на той же `y`, у точки — нет.
Замер (#137): весь ответ на «чем куплен прирост» был только в SVG, текстом эта цифра не
публиковалась нигде.

## Свой транскрипт достаётся одним curl
```bash
curl -s -H "Authorization: Bearer $INTERNAL_TOKEN" --get \
  --data-urlencode "scope=/home/kesha/orchestra" \
  "http://127.0.0.1:8888/api/sessions/<своё-имя>/logs"
```
Отдаёт типизированные строки (`tool`/`tool_result`/`text`/`user_message`) с `id` и `ts`.
**Грабля, на которой я потерял три попытки:** `scope` — это ПУТЬ РЕПОЗИТОРИЯ
(`/home/kesha/orchestra`), а не имя каталога worktree (`home-kesha-orchestra`). Подсмотреть
можно: `sqlite3 -readonly data/orchestra.db "select name,scope from sessions"`.
Заголовок — именно `Authorization: Bearer`, не `X-Internal-Token` (`app/auth.py:54-60`).

## Пишу regex-замену в текст пользователя — только через callable
`re.sub(pattern, block, text)` раскроет `\1` и `\g<0>`, если они попались в подставляемом
тексте (личная память, чужой markdown). Правильно — `re.sub(pattern, lambda _: block, text)`.
И вторая половина той же грабли: если паттерн съедает соседние `\n` (`\n*<tag>`), разделитель
надо вернуть В ЗАМЕНУ, иначе блок склеится с предыдущей строкой. Оба случая поймал прогоном
функции на граничных входах ДО написания тестов — рассуждением не увидел.

## Гард на непустоту спасает от правдоподобного нуля
Считал использование MCP-тулов, получил «0 из 36 используются» — красивое и ложное:
`logs.session_id` по схеме `REFERENCES sessions(id)`, а НЕ `sessions.session_id`
(одноимённое поле рядом, join молча даёт пусто). Спас `assert tot>0`.
Перед агрегатом по собранному на лету списку — всегда гард на непустоту.

## Дословную цитату из веб-доки тянуть только сырым HTML
`WebFetch` пересказывает маленькой моделью — цитата окажется сочинённой. `curl` + снять теги
регуляркой. Сработало на всех источниках #137. Страницы на Mintlify/Next рисуются на клиенте:
если текста после снятия тегов вышло 1-3 КБ вместо десятков — это не пустая страница, а JS,
и данные надо искать в их API (который может требовать ключ — тогда так и писать «не проверял»).
