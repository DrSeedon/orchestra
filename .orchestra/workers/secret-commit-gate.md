# secret-commit-gate — личная память

- **Оболочка Bash-тула здесь zsh: `${PIPESTATUS[0]}` пуст, `set -o pipefail` не действует.**
  Нужен код выхода конвейера → `bash -c 'set -o pipefail; cmd | tail; echo EXIT=$?'`.
  Потерял на этом один прогон: увидел `EXIT=` вместо числа и решил, что команда не отработала.
- **Мутации писать отдельным heredoc-скриптом с ПОЛНОСТРОЧНЫМ якорем, не `sed` по фрагменту.**
  Дважды сломал синтаксис Python, заменив половину многострочного кортежа: pytest отвечал
  `1 error during collection` (EXIT=2), и это читается как «мутация выжила», хотя тест не
  собрался. Признак подмены: `EXIT=2` и `error`, а не `failed`.
- **Мутация выжила → сперва подозревай ВАКУУМНЫЙ тест, а не живучий код.** Проверка gitlink
  не краснела, потому что `git add -A` снимал из индекса запись о submodule, которой нет на
  диске: тест доходил до коммита, ничего не проверив. Лечится ассертом на предусловие внутри
  теста (`assert "160000" in git diff --cached --raw`), а не переписыванием мутации.
- **Полный `pytest` и даже шард из `tests/test_[sr]*.py` умирают `RC=137` (OOM) на ~57–80%.**
  Это свойство репозитория, а не моих правок: проверено прогоном того же шарда с
  `--ignore=<мой файл>` — падает там же. Гонять группами по 4–6 файлов.
