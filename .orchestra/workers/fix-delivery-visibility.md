# fix-delivery-visibility

- A named green regression command is not an oracle for an unreproduced defect. When implementation already exists, add the behavioral regression test and prove it with a focused mutation: mutant red, restore plus `touch`, then green.
- For durable unknown outcomes, the caller-facing formatter must carry the immutable delivery id, status-check tool, and same-id retry rule; preserve existing target/parent warnings when adding an early-return branch.
- When normalizing merge envelopes, enforce target movement and transferred-commit invariants independently of the upstream `ok` flag; contradictory status fields can otherwise resurrect a false Git success.
- When an adapter must call a guarded legacy owner under a process-wide mode, override the mode with a request-local ContextVar and hold serialization across both legacy and projection writes; never mutate the process-global context.
- Non-API documentation paths can redirect anonymous clients to a 200 login page when redirects are followed; auth endpoint oracles must disable redirect following and assert the original response.
