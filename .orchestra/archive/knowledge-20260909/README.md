# Исторический корпус до упрощения памяти, 09.09.2026

Это исходные материалы, не действующие правила. Относительные ссылки внутри сохранённых
файлов относятся к прежнему расположению; для поиска используй исходный путь из manifest.json
и Git-историю. Нельзя восстановить старое правило только потому, что grep нашёл его здесь.

- kb/: полный прежний корпус тем, включая отвергнутые гипотезы и исходные якоря.
- guides/: прежние инструкции CLI, команды и методики.
- workers/: длинные личные заметки; короткие указатели остались в рабочих файлах.
- research/, reviews/, experiments/: исторические отчёты вместе с соседними артефактами.
- manifest.json: исходный путь от .orchestra и SHA-256 сохранённых байтов.

Сначала актуальная KB; при пробеле — адресный rg по этой истории и проверка первичного
источника. Сохранённый текст может содержать снятые требования, несуществующие API и старые
снимки окружения. Исторические цифры не характеризуют сегодняшнее состояние.
