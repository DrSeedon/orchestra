# Задачи, приехавшие с ноутбучного контура

Каталоги `502/` и `503/` пришли с ноутбука вместе со слиянием контуров. Задач с такими
номерами в нашем трекере нет и не было: наш максимум был #501.

Почему они здесь, а не в `.orchestra/tasks/`: выдача номера задачи пропускает номер, у
которого уже существует каталог `.orchestra/tasks/<n>/` (`app/tm.py:179-191`), а canonical
такого правила не знает и требует точного равенства (`app/tm.py:1638`). Из-за двух чужих
каталогов счётчики разошлись 502 против 504, и заведение ЛЮБОЙ задачи в проекте умерло
целиком — включая спавн воркеров.

Настоящее лечение — общее правило выдачи номера для обоих владельцев, оно в работе (#499).
Перенос сюда снимает расхождение немедленно и ничего не теряет: файлы те же, история git та же.
