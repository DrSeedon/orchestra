# Архив личных скиллов владельца

Сюда переносятся личные скиллы, снятые с VPS, чтобы знание осталось в Git, а каталог
агентов не предлагал непригодные маршруты. Файлы здесь — история, не действующая инструкция.

- `agent-teams-SKILL.md` + `agent-teams-references/` — снят с VPS 14.09.2026 по решению
  владельца («удаляй, сохрани куда-то нам в архив в личную историю гит»). Описывал
  встроенные Claude Code Agent/TeamCreate с worktree-изоляцией: 23 260 байт, самый
  крупный скилл каталога. На VPS непригоден — встроенный Agent tool здесь запрещён
  правилом платформы, спавн идёт только через `spawn_worker` Orchestra, поэтому скилл
  оставался приглашением сделать недопустимое. Оригинал лежал в
  `~/.claude/skills/agent-teams/`, удалён через `trash` после этого коммита.
