# Инструменты: поиск кода, результаты вызовов, ресурсы

## Точный поиск и размер вывода

Для пути/символа сначала `rg --files`, `rg -n -F`; открывай совпавший участок, не целый журнал.
Несколько различных якорей передавай через `-e`. Большие tool_result раздувают контекст,
поэтому агрегаты и ограниченные фрагменты полезнее повторных сырых выгрузок.
Для literal-контекста вокруг огромной строки используй смещение/срез, а не широкие
ограниченные regex вида `.{0,N}`: прежние прогоны ловили рост памяти у инструментов на таких шаблонах.

## Результат инструмента против реального действия

Таймаут означает неизвестный исход, не гарантированную отмену. Перед повтором внешнего
действия проверь результат по идентификатору операции. Exit code, доставленная квитанция и
видимый конечный эффект — разные наблюдения. Проверяй тот эффект, который требуется задаче.

## Какие инструменты доступны

Реестр конкретной сессии — источник возможностей. Встроенные subagents рантайма и воркеры
Orchestra различаются жизненным циклом и изоляцией; доступность названия не делает их
взаимозаменяемыми. Не требуй необязательный `search_memory` как гейт до любой правки.
