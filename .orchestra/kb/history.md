# История источников: Git вместо папок-свалок

Полный снимок до очистки: `9a1735f1695519a445f393802c2154bd37337e38`. Коммит достижим из main и содержит прежние workers,
tasks, archive, guides, artifacts. Сырые источники не находятся в активной KB; они нужны
для повторной проверки, а не автоматического чтения в начале задачи.

```bash
git grep -n -i -F '<точный якорь>' 9a1735f1695519a445f393802c2154bd37337e38 -- .orchestra/workers .orchestra/tasks .orchestra/archive .orchestra/guides .orchestra/artifacts
git show 9a1735f1695519a445f393802c2154bd37337e38:.orchestra/tasks/<id>/<file>
```

Читай совпавший раздел и дату; старые инструкции, квоты, версии и статусы не текущие.
Файл без полезного нового вывода не требует отдельной KB-карточки. Активные незакрытые задачи
и используемые тестами данные остаются в рабочем дереве. Полезные повторяющиеся выводы
объединены в тематических файлах, а не скопированы в новый общий архив.

Удаление из checkout не уменьшает размер истории Git. Не переписывай историю ради этой
уборки: закреплённый снимок нужен для восстановления доказательств.
