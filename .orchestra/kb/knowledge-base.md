# Память агентов: KB, личные заметки, поиск

## Один файл по вопросу, доказательства отдельно

`.orchestra/kb/` содержит актуальные проверенные выводы и инструкции по предмету.
`.orchestra/tasks/<id>/` хранит результат задачи и доказательства. `.orchestra/workers/<name>.md`
содержит короткие личные наблюдения. `.orchestra/archive/` хранит прежние тексты, которые
не следует применять как текущие инструкции. Журнал сообщений остаётся в рабочей SQLite.
[Общий порядок записи для всех ролей](../pipelines/default/prompts/modules/knowledge.md).

## Что автоматически попадает в промпт

[app/kb_index.py](../../app/kb_index.py) читает ссылки из `kb/README.md`; в системный промпт
попадает оглавление, не весь корпус. Новая тема должна быть перечислена один раз.
[load_worker_memory](../../app/prompting.py) читает личный файл по имени агента, затем по роли
как fallback; содержимое загружается целиком. Длинные отчёты в личном файле увеличивают
каждый собранный промпт. Подробности оставляй в задаче, здесь — вывод или указатель.

## rg / search_memory / отсутствие семантики

Начинай с точных символов и симптомов: `rg -n -i -F -e '<symbol>' -e '<error>' .orchestra/kb`.
Читай найденный раздел вместе с условиями и источником. Если текущего ответа нет, ищи
адресно в tasks/archive. Отсутствие результата не доказывает отсутствие знания.
[search_memory](../../app/memory_search.py) ищет подстроку в Markdown и исходных логах;
это необязательная альтернатива rg, без отдельной базы, embeddings и RAG-индекса.
Прежние `app/ia/knowledge.py`, `app/rag_service.py`, `current.db`/`vec.db` не являются
владельцами текущей Markdown-KB; старые инструкции typed knowledge API не применяются.
Пути результата и область проекта существенны: личная заметка не становится принятой KB.

## Консолидация без потери доказательств

При исправлении редактируй текущий раздел, не дописывай цепочку взаимоисключающих поправок.
Полезный отвергнутый подход сохрани с причиной и ссылкой. Старые сырые данные не удаляй на
основании одного LLM-конспекта. Архив доступен для повторной проверки, но не загружается
автоматически. Проверка ссылок не подтверждает истинность текста.
