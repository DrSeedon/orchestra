## 5. Может ли dsh заменить Claude Code / Codex для наших воркеров и оркестраторов?

**Вывод: нет, не как замена; как источник отдельных идей (п. 4, 6) — да, а как полный рантайм — только после замера и решения владельца.**

Основания:

1. **Харнес ≠ модель.** dsh — оболочка. Воркер, работающий в ней на DeepSeek, работает с качеством этой модели; от замены Claude Code на dsh+Claude качество модели не растёт. Заявления о победе над Claude Code/Codex в первоисточнике нет — «убийца» это тезис заголовка видео, не данные. В самом репозитории результатов бенчмарков нет (`BENCHMARK.md` — инструкция).
2. **Данных о качестве DeepSeek на наших задачах нет.** У нас есть замеры скорости/цены маршрутов V4.1 Flash (lab V-10, V-11: 9 маршрутов, 81 запрос, все 200) и приёмка vision (V-12, 6/6), но не сравнение качества исполнения воркер-задач против Sonnet/Opus/Sol. «Не измерено» — честная оценка.
3. **Незрелость.** Developer preview, ожидаются ломающие изменения, аудита безопасности нет; для оркестратора, который управляет общим состоянием и деньгами, это риск, а у Claude Code/Codex есть известный контракт интеграции в нашей платформе (steer/interrupt, квотный гейт, учёт стоимости).
4. **У нас уже есть эквивалент для слабых моделей**, причём защиты от петель у нас строже (п. 3 таблицы) — они вырастали из реальных инцидентов GigaChat. Это нужнее для дешёвых моделей, чем плагины.
5. **Применимый путь.** Для пулов хаба и Sol DeepSeek не нужен: правило routing даёт `hubsol` без ограничений. Ниша — дешёвые вспомогательные прогоны и lab-песочница, где он уже открыт. Новый вопрос — прямой API DeepSeek (п. 16), это про деньги, решает владелец.

Что проверить, если владелец захочет двигаться дальше: на фиксированном наборе из N закрытых задач (с известными приёмочными тестами) прогнать нашим харнесом на `deepseek/deepseek-v4.1-flash-1017` и тем же набором на dsh с той же моделью (развёртывание в изолированной папке, вне системы), сравнить долю принятых результатов, раунды и $; эта проверка разделяет влияние харнеса и модели. Цена — один воркер и ~часы, но dsh потребует установки Node/pnpm, что вне границ этой задачи.
