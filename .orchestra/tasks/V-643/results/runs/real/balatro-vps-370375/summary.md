## DECISIONS

Активные, нужные для продолжения:

- **Метрики определены один раз в `src/metrics.js`** и делятся на три семейства: `outcome` (сила — глубина и есть ответ, нормировать нечего), `behaviour` (выбор стратегии, нормировано), `raw` (сырые счётчики за партию, помечены как зависящие от глубины). Считаются из одной строки `runAuto` **без пары** — сознательно, чтобы годились для V-15.
- **Нормировка:** розыгрыши/сбросы → на блайнд и на розыгрыш; очки → на розыгрыш. Зафиксировано честное ограничение: `score_per_play`/`score_per_blind` остаются частично зависимыми от глубины (цели растут по лестнице), полный ответ по очкам даёт только срез общих блайндов.
- **Доля категории — макро** (внутри партии, усредняется по seed'ам), не микро (сумма/сумма).
- **Сравнение на общих блайндах** (`commonBlindMetrics`, срез `i < min(len(A), len(B))`) признано осмысленным, потому что колода на блайнде `i` у обоих одна. Граница вывода записана на странице: набор общих блайндов сам выбран выживаемостью.
- **Нормировка не подменяет вывод о силе**: `blinds_cleared` не тронут.
- **Предложение для V-15, решения владельца нет:** одинаковые seed'ы (`10000…10000+N−1`) для ВСЕХ наборов, иначе парное сравнение внутри лидерборда потребует полного повторного прогона. Двухпроходная схема: 0/1/2 слота полностью по 160 партий (≈1 ч); тройки — скрининг всех 1330 по 60 партий (≈2.2 ч) + добор до 300 для верхушки и контроля (≈0.5 ч); итого ≈3.7 ч в один поток под `nice`, без параллелизма.
