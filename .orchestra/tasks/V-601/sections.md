Оценки ниже — число изменяемых файлов и новых тестовых случаев, не человеко-дни и не бюджет подписки. Общие файлы не суммируются повторно.

3. **Убрать последовательность независимых чтений list_agents.** 3 файла: `app/mcp_stdio.py`, `tests/test_mcp_stdio.py`, `CHANGELOG.md`. 4 новых поведенческих кейса: все чтения начались до разрешения первого; optional tasks error не губит sessions; optional icons error не губит sessions; обязательный sessions error не выдаёт ложный пустой список и все запущенные операции собраны/отменены. 4. **Проверить необходимость более полных receipts и хвосты без выбора архитектуры заранее.** bg_create receipt — условная оценка 3–4 файла/3 теста; merge receipt — 4–5 файлов/4 теста. Дополнительные async операционные протоколы, объединения или удаления — наиболее рискованный вариант и пока не предложены.

Постоянные native-сессии старый catalog могут сохранять, поэтому окончательный deployment-check должен проверить реально выдаваемый tools/list после обновления каждого runtime.
