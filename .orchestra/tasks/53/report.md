# #53 — плашка «Новые bug reports» удалена

Прямое требование юзера. Убрана только плашка в дашборде; серверный механизм
баг-репортов не тронут.

## Что удалено

| место | что |
|---|---|
| `app/templates/dashboard.html` | `<div id="bug-report-banner">` — одна строка |
| `app/static/js/app.js` | блок в 106 строк: `_BUG_INBOX_SEEN_KEY`, `_bugSafeText`, `_hideBugReportBanner`, `_showBugReportError`, `_refreshBugReportStatus`, `initBugReportBanner` + вызов из `DOMContentLoaded` |
| `tests/test_frontend.py` | два теста плашки (118 строк) — удалены вместе с фичей, которую они проверяли |

Ключ `orchestraBugInboxSeenVersion` в `localStorage` больше не пишется и не читается.

## Проверка, что ничего живого не осиротело

Перед удалением посчитал упоминания каждого имени ВНЕ удаляемого куска — все нули,
кроме одного вызова `initBugReportBanner()`, который тоже удалён:

```
_bugSafeText, _BUG_INBOX_SEEN_KEY, _hideBugReportBanner,
_showBugReportError, _refreshBugReportStatus            → 0 упоминаний снаружи
initBugReportBanner                                     → 1 (сам вызов, удалён)
```

Отдельно проверено, что в `app.js` остаётся отрисовка ВЫЗОВА инструмента
`mcp__orchestra__report_bug` в чате (строки 3021, 3535, 4072, 4695) — это другое,
к плашке отношения не имеет и работать должно.

## Потребители серверных роутов (не удалял, как и просили)

- `POST /api/report_bug` — MCP-тул `report_bug` (`app/mcp_stdio.py:1417`). **Живой
  потребитель**, роут нужен.
- `GET /api/report_bug` — на него ссылалась только плашка (`view_url`). Сейчас
  потребителей во фронте нет; читают инбокс вручную.
- `GET /api/report_bug/status` — **потребителей не осталось вообще**. Звала только плашка.

Решение по двум GET-роутам за оркестратором, сам не трогал.

## Побочный выигрыш: опрос раз в 30 секунд

`_refreshBugReportStatus` висел на `setInterval(…, 30000)`:

```
ответ /api/report_bug/status: 99 B, по проводу через nginx 112 B
2 запроса в минуту → за 10-часовой день 1200 запросов, ~131 КБ
```

Немного по байтам, но это 1200 круговых обходов в день на элемент, которого больше нет.
