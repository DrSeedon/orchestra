# V-566 — исполнение пакета V-565

Пакет e858399f скопирован в package/ без изменений чужой ветки. 9/9 SHA256
совпали; before→after заменяет ровно заданную строку. Исходный evaluation.md с
пятью парами исторический; актуальная задача и последующее уточнение родителя
имеют приоритет. Дизайн/семантическая разметка принадлежат prompt-engineer.

Первая серия: Astra/Luna/Opus, по before/after — 6 работ. Сравниваются отдельно
sign(after−before) по total tokens и завершённым tool invocations. Различие знаков
между тремя валидными парами хотя бы по одной метрике разрешает Sol/Fable (ещё 4).
Unknown не знак 0, не основание автоматического добора. Малая разница разрешает
ещё одну пару Astra (2 работы); ≥25% по обеим величинам — бюджетный ориентир для
отказа от повторов, не статистическая значимость. При двух парах доступны только
наблюдённые значения и размах; универсального нулевого эффекта не доказываем.

Три пары выполняются параллельно. Внутри пары условия идут последовательно,
чтобы HOME, CWD, argv и native пути skills были ОДИНАКОВЫ, а не просто похожи.
Astra: before→after; Luna: after→before; Opus: before→after. Повтор Astra —
after→before. Каждый HOME создаётся с нуля, старый переименовывается за границу
доступа до следующего запуска; история/память другого плеча недоступна.

Способ — одноразовые native CLI, task-local readonly_boundary.py (Landlock/seccomp),
streaming/graceful accounting из local_bench.process и provider-only relay.
Это отдельное разовое исполнение read-only задачи, явно разрешённое родителем;
provider-gate local_bench не изменён и не обходится. Userns/AppArmor не меняются.
Все шесть видят один shared read-only каталог с шестью docs; оракул, оба исходных
снимка на диске, основной репозиторий и БД закрыты. Правильный snapshot приходит
только во входном тексте как active_skill, затем дословный task.txt. Родной второй
grill-me не доступен через глобальный HOME/discovery. --ignore-rules отключает
execpolicy rules, а не skills; на него как на выключатель skills не полагаемся.

Landlock не даёт виртуализированный /tmp или полноценный namespace: private HOME
остаётся writable для штатного CLI, обычный /tmp не открыт. Для этой задачи запись
файлов запрещена самим task.txt; попытки фиксируются как отдельные нарушения.
Граница не обещает одинаковость секретных серверных инструкций провайдера: фиксируются
доступный полный user-input, общий system override Claude, CLI/effort/argv/CWD/HOME.
Серверные ids и тайминг не объявляются частью побайтно проверенного текста.

Preflight шести HOME завершился без модельных вызовов: версии CLI и отрицательные
пробы чтения оракула, snapshot, главного репо/DB/global skills; subject write запрещён,
чтение subject разрешено, прямой dashboard TCP запрещён. Реальный argv/proof сохраняется
на плечо. Перед запуском полный scaffold before/after сверяется одной заменой.

Ожидание первой серии: ориентировочно $0.5–2 API-equivalent, не счёт подписки.
Рабочий резерв — $1 на CLI (6 работ); timeout 180s + 20s grace. Codex узнаёт цену
из завершающего usage, поэтому hard dollar cap не обещается. Native Opus max-budget=$1.
Ставки Codex записаны из текущего app.backend_codex.CODEX_TOKEN_PRICES; Claude —
native closing total_cost_usd. Неполный/ошибочный финал не превращается в нулевую цену.

Структура и числа проверяются collect.py; содержательность вопросов размечается
вслепую владельцем дизайна. До разметки семантики/границ пары не считаются принятыми.
Действия — завершённые invocations, отдельно тела docs по фактически доставленным
исходным строкам, частичные чтения и повтор после полной доставки. Объём совпавших
исходных строк — нижняя граница, не выдуманный полный объём при обрезке.

Перед первым запуском prompt-engineer подтвердил: без полного dump не заявлять
побайтное равенство скрытых служебных добавлений CLI; новый сборщик для этого не строить.
