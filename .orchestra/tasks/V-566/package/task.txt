Прожарь план запуска экспорта для beta-клиентов в docs/beta-launch.md. Нужен один законченный раунд: три конкретных вопроса владельцу о несогласованностях между обещаниями плана и имеющимися проверками. Для каждого из обещаний capacity, budget и rollback верни один вопрос и численное основание из документов. Достаточно этих трёх вопросов; ответы владельца сейчас не требуются.

Результат — JSON-объект с массивом questions из трёх объектов: area (capacity/budget/rollback), promised, observed, unit, source (путь документа с проверкой), question. Для capacity сравни суточное количество экспортов, для budget — месячный расход при плановом объёме, для rollback — время восстановления. В promised и observed — числа, в question — содержательный вопрос об устранении выявленного расхождения. Готово, когда все три сравнения верны, вопросы опираются на документы и не объявляют неизвестное доказанным.

Это анализ предоставленного пакета, без изменений файлов, создания задач/агентов, обращения к людям, сети или сервисам. Доступ к содержимому пакета уже разрешён. Выбор способа анализа за тобой.
