# Private handoff для V-1095

Сырые скачанные документы лежат локально рядом с отчётом в `private/`. Вложенный `private/.gitignore` игнорирует всё, кроме самого `.gitignore`. Этот каталог не должен попасть в публичный commit; не использовать force-add. Запрос на публикацию vendor pages не выполнялся.

`evidence/source-manifest.json` содержит исходные URL, конечные URL после redirect, время получения, размер и SHA-256 каждого полного source output. Основные файлы:

- `private/launch-chart-payloads.json`: точные строки шести Vega-Lite specs из hydration, offsets и SHA декодированного hydration-потока. Полная HTML launch-page не сохранена; исходные числовые данные всех графиков сохранены. Browser download был автоматически размещён инструментом во временном служебном каталоге, затем **перемещён** сюда; служебный путь не включён в публикационные артефакты.
- `private/terra.md`, `luna.md`, `sol.md`, `pricing.md`, `selection.md`, `codex-pricing.md`, `codex-models.md`: фактически полученные HTTP 200 outputs документации. Это полные vendor pages, только для локальной проверки.
- `private/system-card.html` и производный `system-card.txt`: официальный system card; txt — локальное HTMLParser-извлечение, не отдельный сетевой ответ.
- `private/telegram-embed.html` и производный txt: публичный вторичный пост, только для проверки состава утверждений, не первичное доказательство.
- `private/validation.txt`: offline проверки и абсолютный путь импортированного app; `read-only-source-hashes.json` — контроль неизменности прочитанного кода.

Private-файлы созданы в разрешённой директории задачи; отдельного общего private-хранилища в выданной копии нет. Broker обещает перенос изменённых файлов, но перенос игнорируемых файлов не проверен изнутри worker. Если после импорта их нет, root должен получить **локальный private handoff** этой директории, не публиковать сырьё и не утверждать, что оно вошло в commit. Публичных числовых evidence и URL/SHA достаточно для обнаружения подмены, но хеш не заменяет отсутствующие raw bytes.

Дополнение владельца: `private/shneural-1435.html`, производный txt и `private/shneural-1435.jpg` — авторский пост и график; они также остаются private. Полный CDN URL картинки есть только в private fetch-manifest; публичный манифест даёт URL поста и SHA полученных байтов.
