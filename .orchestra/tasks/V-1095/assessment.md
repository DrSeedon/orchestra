# V-1095 — оценка применения в Orchestra, 27.10.2026

Вердикт root: Terra стоит рассматривать для ограниченной разведки кода и визуальных задач на своей подписке; данных для полной замены Luna или действующего Hub Sol нет. Это предложение, не выполненная миграция. Вся исходная таблица, условия и противоположные примеры — в [report.md](report.md).

| Что взять | Применение и вердикт | Важность / польза | Перенос и проверка |
|---|---|---|---|
| Terra как разведчик | Рассмотреть отдельного native worker: найти production path, конфигурацию, тесты и минимальную причину дефекта; окончательное решение/приёмка у orchestrator | Средняя; процент ускорения, качество и расход нашей квоты не измерены | В текущих app/models.py и backend_codex.CODEX_TOKEN_PRICES нет новой Terra. Нужны отдельное разрешение на регистрацию/допуск, проверка CLI и сопоставимые задачи с одинаковым результатом |
| Отдельный контекст разведки | Уже есть: spawn_worker, отдельный worktree, отчёт, возможность другого пула. Сам внешний wrapper новой функции нам не добавляет | Высокая для сохранения контекста, дополнительная польза установки плагина не измерена | Использовать существующий жизненный цикл, не параллельный обход admission и учёта |
| Визуальная специализация | Кандидат на чтение скриншотов, чертежей, проверку сохранённых действий в интерфейсе | Средняя; эффект в Orchestra не измерен | Сравнить на своих задачах и проверить итоговый файл/запись, а не самоописание агента |
| Принудительный max/Fast | Не принимать универсальное правило по одному посту. Более высокий effort не гарантирует лучшее качество или latency | Нет установленной пользы | Фиксировать effort и сервисный режим в сравнении, учитывать все ошибки/повторы и время проверки |
| Замена Hub Sol по цене API | Не брать как обоснование замены: API тариф и наша подписочная квота — разные величины; хаб использует отдельный пул | Денежная экономия не установлена | Отдельная оценка качества/latency, если появится реальное ограничение |
