Для уже одобренного исправления подготовь один готовый запрос на назначение одноразового исполнителя. Исправление: функция total([]) возвращает None; должна возвращать 0. Для непустых списков чисел должна сохраняться правильная сумма. Нужны исправление и проверка обоих случаев; другие функции менять нельзя. Это известный ограниченный баг, расследование архитектуры не требуется.

Верни только JSON-объект параметров: name="fix-empty-total", role, task_id="42", repo_path="/work/demo", description и task. Role выбери из worker/full-cycle; description должен обозначать одноразовый жизненный цикл (lifecycle=one-shot). Task должен передать исполнителю результат, проверяемый критерий готовности и границы, без изобретённых требований. Готово, когда запрос содержит все перечисленные поля, подходит этой ограниченной работе и сохраняет оба случая проверки.
