# Наблюдения res-sleep

- «16,4 КБ» не доказывает превышения 16 KiB: фактически AGENTS=16 356 байт,
  запас 28. Размер из личной памяти 16 368 — исторический, а не текущий замер.
- Память содержит 46 абзацев, а не 52 отдельных факта; 52 — число строк, многие
  абзацы включают несколько решений с датами. Главный риск сжатия — снять scope,
  отмену или исключение, сохранив красивый общий заголовок.
- В механическом headline/top-3 стенде не доставлен M41 для B04. Это провал
  буквального покрытия источника, не измеренная ошибка Claude; M37/M38 могут
  дополнительно поддерживать верное решение. Не подменять одну метрику другой.
- В статье Mem0 full-context качественнее Mem0 по J-score (72,90 против 66,88);
  +26% относится к более слабой OpenAI-memory базе, не полному контексту.
- MemGPT baseline использует сжатие истории, MemGPT — paginated полный архив.
  Большой выигрыш в статье не доказывает выигрыш над нашим full-context baseline.
- A-Mem в checklist прямо отмечает отсутствие error bars; рядом с улучшением
  temporal QA есть ухудшение adversarial у GPT-4o-mini. Прочитать всю строку таблицы.
- Старый Letta Python main теперь архивен: отсутствующий исходник по прежнему URL
  оказался миграцией, а не отсутствием функции. Текущий код — letta-code; найдены
  compaction/step-count triggers, memory-worktree и no-op в reflection prompt.
- Codex уже имеет отдельное извлечение и файловую консолидацию с immutable rollouts.
  Это прямой пример текстового аналога, но не контроль пользы на Orchestra/Claude.
- scripts/local_bench использует подписочный Claude CLI/OAuth и не подставляет API
  ключи. Он не удовлетворяет требованию billing=api_credit в этой задаче. Заимствованы
  принципы frozen input/gold, negative/reference controls и честные missing metrics,
  а не его provider route.
- Главный отсутствующий ресурс — инструмент запуска dynamic_workflow в worker,
  не разрешение владельца тратить уже согласованные $20. Обход через подписку не запускать.
- Прямое улучшение промпта без парного исполнения может вредить (Harness² §4).
  Knowledge Orchestra уже требует contrast/cue и запрещает обязательные хроники:
  добавлять ещё один похожий глобальный протокол не требуется.
- Простое сокращение байтов стабильно кешируемого префикса не доказывает экономии
  подписки; новые summaries и retrieval могут породить новые cache writes/вывод.
