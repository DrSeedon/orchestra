# V-861 — мутационный гейт и исключённые тесты

## Причина

В `feat-voice-input` менялись `app/static/js/chat.js` и `tests/test_frontend.py`. Вместе с четырьмя браузерными тестами ветка добавила fixture и screenshot/helper функции. Изменённые строки вне `test_`-функций переводили AST-сопоставление на file fallback; mutation probe запускал соседние неизменённые функции. Браузерные тесты затем исключались маркером, а 14 зелёных небраузерных тестов давали ложное `tests_not_guarding_source`.

## Изменение

Mutation gate теперь запускает для доказательства только test-функции, чьи строки добавлены или изменены в ветке. Изменение helper/import без идентифицируемой изменённой тест-функции не превращает весь модуль в доказательство: такой mutation результат `SKIPPED` с причиной `changed_test_nodes_unresolved` или `no_changed_test_nodes`.

Для mutation tree отдельно передаётся политика маркеров исходного Orchestra worktree. Сам временный архив не имеет общего Git common-dir с Orchestra, поэтому автоматическое распознавание проекта там не срабатывает. `browser` и `live_probe` исключаются тем же выражением, что в основном тест-гейте. Если control сообщает, что все выбранные изменённые узлы исключены, mutation gate возвращает `SKIPPED / changed_tests_excluded` и не объявляет их негардящими.

Изменённый небраузерный тест, который проходит с исходниками target, по-прежнему даёт `FAILED / tests_not_guarding_source`. Для файлов, где добавленные строки нельзя сопоставить с тестовыми функциями, гейт не делает отрицательный вывод по всему файлу.

## Проверки

- `uv run --frozen python -m pytest --rootdir=. -c pyproject.toml -q tests/test_merge_test_gate.py tests/test_merge_gate_mutation_702.py` — **57 passed in 67.70s**. Регрессионный synthetic diff добавляет helper и новый marker-тест рядом с неизменённым тестом: выбран только новый узел.
- Мутация после коммита теста принудительно отключала исключение маркеров в mutation tree. Обе параметризации (`browser`, `live_probe`) покраснели: результат стал `passed` вместо требуемого `skipped`. Мутация снята.
- `git diff --check` прошёл.

## Ограничение

Если diff тестового файла синтаксически не позволяет связать изменённые строки с конкретными test-функциями, mutation verdict пропускается вместо того, чтобы считать неизменённые тесты доказательством. Основной тест-гейт при этом остаётся отдельным и продолжает проверять mapped-файлы с обычным исключением `browser`/`live_probe`.
