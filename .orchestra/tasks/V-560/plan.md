# V-560 — локальный переиспользуемый стенд

Одобрена реализация, не платные прогоны. Работа продолжена в имеющемся изолированном
worktree; база результата V-558 — 8e8f0783. Никаких изменений app/, MCP или сервиса.

Интерфейс: `python -m scripts.local_bench plan|run CONFIG.json`. Конфигурация задаёт
снимок исходников, текст задачи, immutable oracle, baseline/reference-контроли и плечи.
Результат — JSON/Markdown + stdout/stderr, diff и показатели учёта; одинаковые SHA входа,
параллельный старт всех плеч, отдельные completion/source_pass/accounting состояния.
Провайдеры только при явном --allow-provider; offline fixture-плечи не обращаются к ним.

Изоляция provider-плеч: bwrap с отдельным /tmp, /proc и файловыми mount, clean HOME;
Landlock только для TCP-доступа к provider-only relay. Старый Landlock-only режим,
который ломал /proc и /tmp, не предоставляется как равноценный безопасный fallback.
На текущем хосте bwrap отсутствует и unshare недоступен: preflight должен явно отказать
до provider-вызова. Это локальная зависимость инструмента, не изменение инфраструктуры.
Offline end-to-end и тесты lifecycle выполняются здесь без неё и без провайдеров.

Лимит времени: SIGINT с grace для закрывающего usage, затем TERM/KILL при необходимости;
все события и прогрессивный accounting сохраняются до завершения. Если процесс не выдал
финальное событие даже при grace, результат явно incomplete (никогда $0/полный счёт).
Точный счёт физически нельзя восстановить из отсутствующего события; тесты обязаны
проверять и сохранение финального счётчика при SIGINT, и честную неполноту при hard kill.

Подготовка: elapsed стенда отдельно от arm wall/usage, author/preparation cost вводится
как явно помеченная атрибуция пользователя; неизвестное значение остаётся null, не 0.
Отношение подготовки к стоимости плеч показывается только при полном учёте обеих сторон.
