## 4. Что делает bridge и чем отличается Orchestra

OpenCode v2.2.3 использует JS SDK **0.3.301** (package.json). `io.ts` выбирает `OPENCODE_CLAUDE_PATH` либо `claude` с PATH; `session.ts` вызывает SDK `query`. External-login marker (`integration.ts`, schema `Credential.External`) не содержит OAuth access/refresh. Авторизация и обновление входа принадлежат CLI. Путь к executable настраиваемый: сам этот код не аттестует неизменность бинарника.

`query-options.ts` объединяет process env → connection overrides → isolation env. Он отключает штатные инструменты Claude, user/project settings sources, hooks, auto-memory/compaction и передаёт инструменты OpenCode по MCP (`mcp__opencode__*`). Значит, меняются инструменты, permissions и история; копирование этих опций в Orchestra не является простой сетевой правкой. Минимальная версия CLI для чата — **2.1.248**, расширенное обнаружение контекста — **2.1.257** (`probe.ts`). Встроенный probe запускает CLI и получает initialization/account information; **мы его не запускали**, даже без отправки prompt.

Понятные примеры применимости:

1. Воркер `hubsol` медленно отвечает: VPS возле ноутбука меняет доставку задания к хабу, но из этого нельзя заключить, что изменился путь хаб → модель. Сначала требуется определить слой сбоя; покупка VPS по данному исследованию не обоснована.
