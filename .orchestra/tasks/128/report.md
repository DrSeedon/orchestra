## TL;DR

Гипотеза оркестратора («сухость — следствие переноса принципов вместо конкретики»)
**подтверждается, но не там, где ожидалось.** Числа говорят следующее:

- Где мы перенесли **дословный синтаксис** — правило исполнено в 5 артефактах из 5.
- Где мы оставили **принцип без значений** — правило не появилось нигде.
- Где мы **не написали ничего** — пусто, разумеется.

Но главная причина «сухости» — не палитра и не радиусы. Она измеряется одной строкой:
**все пять артефактов рендерятся одним и тем же системным гротеском начертания 400,
пары шрифтов нет ни в одном.** Наш пункт 3 «Системные шрифты, без веб-шрифтов» — это
прямое противоречие единственному правилу OpenAI про типографику, и оно наше собственное,
не заимствованное.

Ответ на вопрос «правила или скелет»: **скелет.** Обоснование — доза-эффект ниже, оно
измеренное, а не вкусовое. Цена: +2 924 Б к телу скилла, и цена эта дешевле, чем считалось
в #119 (тело больше не вклеивается в промпт целиком).

## 1. Проверка гипотезы: доза-эффект

Все числа — по 5 артефактам `docs/tasks/119/measure/after/` (новый скилл) против 5 таких же
`before/` (старый). Скрипт: `docs/tasks/128/richness.py`, запуск в одну команду.

| Что стоит в скилле | В какой форме | Что получилось в артефактах |
|---|---|---|
| `light-dark(светлое, тёмное)` | дословный синтаксис | **5/5**, 4–8 вхождений на файл (было 0) |
| `--card: color-mix(in oklab, var(--ink) 5%, transparent)` | дословная строка | **5/5**, 3–6 вхождений (было 0–4) |
| `calc(var(--fs) * 1.72 / 1.43 / 1.29)` | дословные коэффициенты | **5/5**; 65 из 77 объявлений `font-size` выведены из переменной (было **0 из 77**) |
| `outline: none; box-shadow: inset 0 0 0 1px var(--ring)` | дословная строка | **5/5**, 1–2 `:focus-visible` (было 0–1) |
| «радиусы из одного `--radius`: `.6 / .8 / 1`» | коэффициенты без базы | 4/5 (у схемы — ни одного скругления) |
| «Серии графиков — 6 различимых тонов» | принцип без значений | **0/5** токенов серий |
| «Тень — состояние, не украшение» | принцип без значений | 1–2 тени на файл (у Codex — 12, из них 9 фокусных) |
| «меняй композицию, плотность, **шрифтовую пару**» | принцип без значений | **0/5**: второй шрифтовой семьи нет ни в одном |
| про движение — **ни слова** | отсутствует | `@keyframes` **0/5**, `transition` 0–1, `:hover` 0–1 |
| про таблицы — **ни слова** | отсутствует | таблицы есть в 4/5, `tabular-nums` — медиана 0, `.sr-only` 0/5 |

Зависимость монотонная и без исключений: **чем буквальнее формулировка, тем выше исполнение.**
Принцип без значения не исполняется «минимально» — он не исполняется вовсе.

**Честная оговорка про серии.** 0/5 — не провал правила, а неопределённость: ни в одном
из пяти артефактов нет графика вообще (`<canvas>`/Chart.js/uPlot — 0 вхождений). Метрика
не измерена, а не провалена. Записываю как есть.

**Поправка к собственному замеру.** Сначала я насчитал по `grep 'font-family'`, что четыре
артефакта из пяти не объявляют шрифт вовсе. Это артефакт грепа: семья задаётся сокращением
`font:`. Проверка рендером (headless Chromium, вычисленный стиль) даёт настоящую картину:

```
P1-postmortem  body=system-ui, -apple-system, "Segoe UI", Roboto…  weight=400  h1=та же семья
P2-comparison  body=ui-sans-serif, system-ui, -apple-system…       weight=400  h1=та же семья
P3-dashboard   body=system-ui, -apple-system, "Segoe UI", Roboto…  weight=400  h1=та же семья
P4-diagram     body=system-ui, -apple-system, "Segoe UI", Roboto…  weight=400  h1=та же семья
P5-plan        body=system-ui, -apple-system, "Segoe UI", Roboto…  weight=400  h1=та же семья
```

Пять артефактов, пять одинаковых гротесков, заголовок той же семьёй, начертание 400 везде.
У Codex базовое начертание — `430`, заголовочное — `500`, и это отдельные токены.
Вот это и читается как «без дизайна» раньше любой палитры.

Полная таблица — `docs/tasks/128/comparison.tsv`, 54 строки, вердикт на каждой.

Разрез по источникам объясняет всё:

| источник | ЕСТЬ | РАЗМЫТО | НЕТ | ПРОТИВОРЕЧИТ |
|---|---|---|---|---|
| текстовые правила `gpt-5.5` (19 применимых) | **8** | 3 | 8 | 0 |

**Вот она, цена решения #119 одной строкой:** текстовые правила мы перенесли почти наполовину,
а дизайн-систему — на одну двадцатую. Мы взяли то, что было написано словами, и не взяли то,
что было написано кодом.

Три «ПРОТИВОРЕЧИТ» стоит назвать поимённо, они не случайны:

1. **Шрифты.** OpenAI (≤5.4): «избегать дефолтных стеков (Inter, Roboto, Arial, system)».
   Мы: «Системные шрифты, без веб-шрифтов». Наше правило родилось из требования офлайна —
   но офлайн запрещает веб-шрифты, а не разнообразие. Локальные семьи (`ui-serif`, Georgia,
   Charter, Palatino, `ui-rounded`) доступны офлайн и дают пару.
2. **Фон.** OpenAI (≤5.4): «не плоская заливка, добавь атмосферу градиентами и паттернами».
   Мы (вслед за 5.5): «без градиентных пятен, шаров и клякс». Здесь противоречие не наше:
   OpenAI сама развернулась на 180° между поколениями. Остаёмся на стороне 5.5 сознательно.
3. **Когда вообще рисовать.** Sol: «визуал только если он существенно облегчает понимание».
   Наш `description`: триггерить агрессивно. Это осознанное расхождение, менять не предлагаю.

## 5. Предложение по переносу

### 5.1 Что переносим дословно

Костяк целиком — черновик лежит в `docs/tasks/128/proposed-skeleton.css`, **3 896 Б**.
В нём дословно перенесены значения:

| Что | Значения |
|---|---|
| производные цвета | `--card: color-mix(in oklab, var(--ink) 5%, transparent)`, `--muted` 50%, `--border` 12%, шапка таблицы 16% |
| шкала кеглей | `1.72 / 1.43 / 1.29` + нижний предел `max(11px, calc(var(--fs) - 2px))` |
| начертания | 430 для текста, 500 для заголовков, интерлиньяж 1.5 / 1.25 |
| радиусы | `.6 / .8 / 1.6` от одной базы + `9999px` |
| тень | `0 1px 2px -1px rgb(0 0 0 / 8%)` — ровно одна на файл |
| палитра серий | шесть тонов с парой light/dark на каждый, дословно из `--viz-series-1..6` |
| фокус | `outline: 2px solid var(--ring); outline-offset: 2px` + отдельное состояние «выбрано» по `[aria-pressed]` |
| таблица | линии только снизу, последняя строка без линии, шапка контрастнее, `tabular-nums` в числовых колонках, горизонтальная прокрутка |
| ритм отступов | закрытый ряд 2 4 6 8 12 16 24 40 |
| сетка | `repeat(auto-fit, minmax(max(180px, 24%), 1fr))` |
| мелочи | `box-decoration-break: clone` у инлайн-кода, `svg { display:block; max-width:100% }`, `.sr-only` |

Плюс два текстовых правила, которых у нас нет и которые к документу применимы дословно:
«стабильные размеры через `aspect-ratio`/`min-max`, чтобы ховер не двигал вёрстку» (D17)
и «словарь контролов» в усечённом виде (D1).

### 5.2 Атрибуция

Apache-2.0 требует сохранить уведомление об авторстве и отметить изменения. Практически —
одна строка в теле скилла (86 Б):

```
<!-- костяк производен от visualize.css, (c) OpenAI, Apache-2.0 -->
```

и полный исходник с шапкой происхождения уже лежит в `docs/tasks/128/verbatim/05-visualize.css`
(там же перечислено, что именно изменено). Этого достаточно: мы не выдаём чужое за своё
и не удаляем уведомление.

### 5.3 Цена в байтах

```
скилл сейчас                        7 065 Б
+ костяк                            3 896 Б
+ строка атрибуции                     86 Б
− секция «Размеры — шкалой»          −687 Б   (её заменяет костяк)
− секция «Состояния»                 −371 Б   (её заменяет костяк)
────────────────────────────────────────────
итого                             ≈ 9 989 Б   (+41%)
```

**Цена ниже, чем считалось в #119.** Отчёт #119 утверждал, что для Sol-воркеров тело скилла
вклеивается в системный промпт целиком — **это утверждение устарело.** В `app/prompting.py:239`
(`build_skills_index`) в промпт уходит только строка `- имя — описание — путь`; тело агент
читает сам и только когда скилл сработал. То есть 2 924 Б платятся один раз за сессию,
в которой артефакт действительно делается, а не в каждой сессии подряд.

## 6. Главный вопрос: хватит ли текстовых правил

**Не хватит. Нужен скелет.** Три довода, все опираются на числа выше.

1. **Доза-эффект монотонный.** Дословный синтаксис → 5/5. Коэффициенты без базы → 4/5.
   Принцип без значений → 0/5. Экстраполяция очевидна и проверяема.
2. **Точных коэффициентов мало.** Шкалу кеглей мы перенесли ЧИСЛАМИ (1.72/1.43/1.29) — и
   всё равно получили 11–22 различных кегля на файл против шести именованных у Codex.
   Ограничивает разброс не точность числа, а **закрытость набора**: у них шесть имён и
   седьмого взять неоткуда. Закрытый набор словами не описывается, он либо есть в коде, либо нет.
3. **Цена низкая** (см. 5.3) и платится по факту использования.

**Возражение, которое я обязан назвать сам:** скелет — это одинаковый вид у всех артефактов,
то есть ровно та монотонность, на которую юзер жалуется с другой стороны. У Codex один
фирменный стиль потому, что это одна поверхность одного продукта; у нас артефакты должны
отличаться по предмету, и #119 это уже вымерил (5 из 5 уникальных акцентов).

**Разрешение противоречия — в форме скелета.** Переносим МЕХАНИЗМ и оставляем ВКУС:
пять «ручек» сверху файла (акцент, база кегля, база радиуса, основная семья, заголовочная
семья) агент выбирает под предмет, всё ниже копирует без изменений. Механизм — то, что
у нас не исполнялось. Вкус — то, что как раз исполнялось: 5/5 уникальных акцентов, когда
попросили выбрать цвет под предмет.

Одновременно снимается противоречие №1 из раздела 3: «заголовочная семья» становится
обязательной ручкой, и офлайн при этом не нарушается — семьи берутся локальные.

## 7. Чего НЕ переносим

- **Тултип на Floating UI и иконки lucide** — внешний JS с `unpkg.com`, ломает офлайн.
- **`#widget`, `html > body { background: transparent }`, `::codex-inline-vis`** — привязка
  к их вьюеру; нам нужен самостоятельный документ.
- **Правила про лендинги, hero, Three.js, дев-сервер, React** — 7 строк «не наш жанр».
- **Инструкции ChatGPT Canvas** — не подтверждены нашим извлечением, другой продукт, 2024 год.
- **`corner-shape: superellipse(1.5)`** — поддержка только в свежих браузерах; при желании
  можно, деградирует безопасно, но в костяк не клал.

## 8. Ограничения и чего я не проверял

- **Прироста не измерял.** Всё выше — разбор материала и причин; доказательство, что скелет
  действительно делает артефакты живее, требует такого же прогона, как в #119
  (N сессий на старом теле против N на новом). Пока это гипотеза с сильным основанием,
  а не измеренный эффект.
- Замеры сделаны на 5 технических артефактах — той же выборке, что и в #119. По правилу,
  принятому там же, эффект правки надо будет перепроверить на 1–2 далёких темах.
- Живого рендера `::codex-inline-vis` не видел: Codex вызывать нельзя до 08.08 (лимит).
  Всё про их дизайн-систему — из байтов, первоисточника и официального дока.
- Внешнего ревью нет по той же причине. **Вердикта второй модели у этого отчёта нет.**
