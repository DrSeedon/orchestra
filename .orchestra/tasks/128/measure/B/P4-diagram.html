Путь задачи через оркестратор

Один прямой маршрут: задача от пользователя, воркер в отдельном worktree, гейт ревью, squash-мерж в main. Две петли возврата — красные — и есть вся система: непройденное ревью возвращает работу в ту же ветку, упавший воркер возвращает решение оркестратору.

Ревью не прошло

Работа есть, качества нет. Воркер жив и остаётся на своей ветке: правки идут туда же, гейт проходится заново. Ни спавна, ни нового worktree.

Воркер упал

Работы может не быть вовсе. Решает оркестратор: снять незакоммиченное через worker_wip, закоммитить за воркера и переспавнить. Ветка переживает воркера.

Мерж в main

Единственный выход из контура — merge_worker, squash. Пока коммит не в main, задача не закрыта, чей бы отчёт о ней ни лежал.
