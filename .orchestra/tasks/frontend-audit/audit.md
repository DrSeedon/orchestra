# Frontend Design Audit — Orchestra Dashboard

Аудит глазами дизайнера (не кодера). Метрики собраны с живого дашборда (localhost:8888, 1440×900) + грепом по CSS/HTML.

**Вердикт одной строкой:** крепкий "developer tool", НЕ студенческий хакатон — но и не polished product. Уровень «внутренний инструмент, который не стыдно показать, но до Linear/Vercel не дотягивает». Основная болезнь — **отсутствие дизайн-системы**: цвета/радиусы/шрифты выбирались по месту, а не из палитры токенов.

---

## 1. Цветовая палитра

**Факт:** 36 уникальных hex-цветов в CSS/JS. Топ по частоте: `#22c55e` (green ×55), `#64748b` (slate-500 ×51), `#94a3b8` (slate-400 ×43), `#38bdf8` (sky ×39), `#a78bfa` (violet ×34), `#ef4444` (red ×30), `#eab308` (yellow ×24), `#818cf8` (indigo ×23).

**Что хорошо:**
- Ядро — это Tailwind slate-шкала (`#64748b/#94a3b8/#475569/#334155/#1e293b`) + семантика (green=ok, red=error, yellow=idle). Система ЕСТЬ, просто не оформлена.
- Семантика статусов читаемая: зелёный=running, жёлтый=idle, красный=error — интуитивно.

**Что плохо:**
- **7+ синих/фиолетовых оттенков делают почти одну работу:** `#38bdf8`(sky), `#818cf8`(indigo), `#a78bfa`(violet), `#6366f1`, `#c4b5fd`, `#c7d2fe`, `#60a5fa`, `#3b82f6`. Глаз не считывает разницу между "tool=sky" и "accent=indigo" и "module=violet" — выглядит как «взяли что попало».
- **3 разных красных** (`#ef4444`, `#f87171`, `#fca5a5`, `#fecaca`) и **3 зелёных** (`#22c55e`, `#4ade80`, `#86efac`, `#bbf7d0`) — часть оправдана (bg/border/text тон), часть — дубли.
- **Нет CSS-переменных.** Каждый цвет — magic hex в 50 местах. Сменить акцент = find/replace по 36 значениям.

**Предложение (точные значения):**
Ввести токены в `:root` и свести палитру к **≤14 переменным**:
```css
:root {
  --bg: #0a0e17; --surface: #0f172a; --surface-2: #1e293b;
  --border: #334155; --border-soft: #1e293b;
  --ink: #e2e8f0; --ink-soft: #94a3b8; --ink-faint: #64748b;
  --ok: #22c55e; --warn: #eab308; --danger: #ef4444;
  --accent: #818cf8;       /* ОДИН акцент, не три */
  --accent-alt: #38bdf8;   /* второй — только для tool/link, дисциплинированно */
}
```
Выпилить `#6366f1/#3b82f6/#60a5fa/#a78bfa/#c4b5fd/#c7d2fe` → заменить на `--accent`/`--accent-alt`. Фиолетовый (`#a78bfa`) оставить ТОЛЬКО за subagent/module — одна роль, один цвет.

**Приоритет: P1** (высокий визуальный ROI, но объёмный рефактор).

## 2. Типографика

**Факт:** JetBrains Mono для ~493 из 557 текстовых узлов (88%). **9 размеров шрифта в ходу:** 9, 10, 10.8, 11, 12, 12.6, 14, 16, 18px. Дробные (10.8/12.6) — это Tailwind `text-[10px]` × zoom, шум.

**Что хорошо:**
- Моноширинный для кода/логов/метрик/путей — **правильно** (выравнивание чисел, diff-ы, токены). Для dev-tool это фича, не баг.
- 16/18px заголовки задают иерархию.

**Что плохо:**
- **JetBrains Mono для ВСЕГО, включая длинные русские абзацы в чате** — моноширинный текст на кириллице читается тяжелее пропорционального (буквы растянуты, межбуквенное неестественное). Абзацы отчётов агентов — стена одинаковых по ширине символов.
- **9 размеров = нет шкалы.** 9 и 10 и 11 px рядом — глаз не различает, но код усложняется. Настоящая иерархия — 4-5 ступеней, не 9.
- 9px местами (cache-pill, meta) — **на грани читаемости**, особенно на не-retina.

**Предложение:**
- **Гибридная типографика:** мониширинный — код/логи/метрики/пути/числа. Пропорциональный (`Inter`/`system-ui`) — чат-абзацы, описания, заголовки, кнопки. Это единственное изменение, которое сразу поднимет «ощущение продукта».
- Свести к **шкале из 5**: `--text-xs:11px, --text-sm:12px, --text-base:14px, --text-lg:16px, --text-xl:18px`. Выпилить 9px (min 10px), 10.8/12.6 (артефакты).
- Line-height для абзацев чата: сейчас плотно, поставить `1.55`.

**Приоритет: P1** (гибрид шрифтов — самый заметный «wow» за малую кровь).

## 3. Layout

**Что хорошо:**
- Трёхколоночник (files / chat / agents) — стандартный, понятный, как в IDE. Пользователь не теряется.
- `overflow-hidden` фиксирует вьюпорт, внутренние скроллы изолированы — правильно.
- Chat центральный и широкий — верный акцент (это главный экран).

**Что плохо:**
- **Right panel (agent-info + список) плотновата.** Model/Role/Cost/Branch/Scope грид `gap-y-1` — строки липнут друг к другу, «Scope: /mnt/data/...» переносится и ломает ритм.
- **Плотность верхних баров:** usage-bar (28px) + header (50px) + иногда rate-banner — три горизонтальных полосы съедают ~80px до контента. На ноуте 900px это заметно.
- **Пустое пространство под agent list** не используется (в скриншоте — низ правой колонки пустой), тогда как agent-info сверху зажат.

**Предложение (точные):**
- Agent-info грид: `gap-y-1` → `gap-y-1.5` (6px), label `text-[11px]` цветом `--ink-faint`, value — `--ink`. Scope — обрезать в одну строку с `title` tooltip (как уже делаем для desc), не переносить.
- Header + usage-bar: объединить cost/agents-счётчик из header В usage-bar (он и так про метрики) → минус одна полоса, +28px контента.
- Spacing-шкала: ввести `--space-1:4px … --space-4:16px`, использовать вместо разнобоя `mt-0.5/mt-1/mt-2`.

**Приоритет: P2** (работает, но можно дышать свободнее).

## 4. Элементы (кнопки, badges, pills, tabs)

**Факт:** border-radius в **6 вариантах** — `4px, 6px, 8px, rounded-lg(8px), rounded-xl(12px), rounded-full/9999px, 3px`. Padding кнопок в **8 вариантах** (`px-3 py-2`, `px-2 py-1`, `px-4 py-2`, `px-2 py-1.5`, `px-2.5 py-1.5`…).

**Что хорошо:**
- Pills (cache-timer, status, ACTIVE badge) — визуально приятные, `rounded-full`, компактные.
- Glass-модалки (`.glass`) консистентны, blur+border выглядят современно.
- Иконки-кнопки в header (🌐🗂📊📋⟳) — единый размер, единый hover.

**Что плохо:**
- **Кнопки — зоопарк.** Header-иконки `px-2 py-1 rounded-lg`, Send `rounded-lg`, proxy-select `px-2 py-0.5 rounded`, send_file `border-radius:6px`, tabs `rounded-full`. Нет ощущения одной руки — каждый компонент лепился отдельно.
- **Два способа делать badge** — где-то `<span class="text-[9px] px-1 py-0.5 bg-.../30 rounded">`, где-то inline-style pill. Дубль паттерна.
- **6 радиусов** — глаз считывает несогласованность подсознательно (углы то острее, то круглее).

**Предложение:**
- Радиус-шкала из **3**: `--r-sm:6px` (badges/pills-small), `--r-md:8px` (buttons/inputs), `--r-lg:12px` (cards/modals). `rounded-full` — только для круглых статус-точек и tabs. Выпилить 3px/4px.
- **Один класс `.btn`** с вариантами `.btn-ghost` / `.btn-primary` / `.btn-icon` — вместо 8 inline padding-комбинаций. Padding кнопки: `6px 12px` (default), icon-btn `6px`.
- **Один класс `.pill`** (уже начал с `.cache-pill`) — обобщить на status/ACTIVE/task-type.

**Приоритет: P1** (консистентность элементов = 80% «ощущения продукта»).

## 5. Dark theme

**Что хорошо:**
- `#0a0e17` фон — глубокий сине-чёрный, приятный, не «чёрная дыра» (#000) и не «серый номер отеля». Хороший выбор.
- Surface-слои (`#0f172a` chat bg, `#1e293b` borders) дают глубину.
- Основной текст `#e2e8f0` на `#0a0e17` — контраст **~14:1**, отлично (WCAG AAA).

**Что плохо:**
- **`--ink-faint` `#64748b` на `#0a0e17` = контраст ~4.1:1** — впритык к WCAG AA (4.5), на meta/timestamp/9px это **уже мелко И бледно** одновременно. Двойной удар по читаемости.
- `#475569` (ещё бледнее, ×17 использований) на фоне — **~3:1**, ниже AA. Line-numbers, faint-подписи — теряются.
- Glass `rgba(15,23,42,0.8)` поверх тёмного контента иногда даёт мутный слой с низким контрастом границы.

**Предложение:**
- Поднять faint-текст: `#64748b` → `#7c8ba1` (контраст ~5.2:1). Timestamp/meta станут читаемы без потери «второстепенности».
- `#475569` для line-numbers → `#5a6b82`. Мелкое, но глаза скажут спасибо.
- Bg оставить `#0a0e17` — он хорош. НЕ трогать.

**Приоритет: P2** (доступность + читаемость, малый diff).

## 6. Общее впечатление

**Professional tool или «студент на хакатоне»?**
→ **Крепкий 7/10 developer tool.** НЕ хакатон (layout продуман, dark theme со вкусом, функциональная плотность как у Grafana/Linear). НО и не 9/10 product — выдаёт «сделано инженерами для инженеров, без прохода дизайнера»:
- Разнобой радиусов/цветов/кнопок = «лепилось инкрементально» (что правда — каждая фича отдельным воркером).
- Моно-шрифт на всём = «дев не заморочился про читаемость абзацев».
- 9px текст = «влезло бы — и ладно».

**Что уже на уровне продукта:**
- Cache-timer pills, streaming с курсором, usage-графики, diff-картинки — фичи, которых нет у конкурентов. Функционально — сильнее вида.
- Glass-модалки, статус-система, трёхколоночник — грамотно.

**Топ-3 изменения для максимального «product feel» (по ROI):**
1. **Гибридный шрифт** (Inter для абзацев/UI, mono для кода) — №1 по «wow», ~1 день. (§2)
2. **Дизайн-токены** (`:root` переменные, ≤14 цветов, 3 радиуса, 5 размеров) — фундамент, убирает разнобой. (§1,4)
3. **`.btn`/`.pill` компоненты** вместо inline-зоопарка — консистентность. (§4)

Эти три подняли бы с 7/10 до ~8.5/10 без переписывания логики — чистая косметика поверх токенов.
