Когда что использовать

  • Название модели в интерфейсе → modelBadge(id) / modelBadgeHtml(id) из theme.js; цвет выбирается по семейству (opus, sonnet, luna…), неизвестная модель — цвет поставщика.
  • Статус агента → .ds-status[data-status] с иконкой из _STATUS_ICON и подписью T(status); одна только точка — .ds-status-dot.
  • Canvas, Chart.js, SVG-атрибуты → modelColor(), providerColor(), cssToken('--…'): туда var() не подставится.
  • Новый hex в style.css или JS не пишем: нужен новый смысл — новый токен в design-system.css.
