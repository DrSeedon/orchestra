# V-1116 — защитный отказ при пустом owned_dirs

Добавлен класс `hub owned_dirs guard refusal` в `_NOISE` и `_EXPECTED_HUB_NOISE`.
Шаблон сопоставляет стабильную фразу `this hub worker has no owned_dirs, and only projects marked persistent`.
Поэтому отказ уходит в шум при группировке и исключается из повторов в `post_fix_verdict`.
Остальные классы шума и `app/hub_workspace.py` не изменены. В `CHANGELOG.md` добавлена запись Fixed рядом с V-1115/V-1111.

Нюанс: `normalize_signature` заменяет путь конфигурации внутри отказа.
Шаблон заканчивается до этого пути, поэтому одинаково работает с исходным сообщением и нормализованной сигнатурой; менять нормализацию не потребовалось.
Формат сохранённого состояния и механизм восстановления не меняются.

Проверки выполнены provisioned uv 0.11.28, с frozen lock и стандартной `.venv`:

- До исправления: `uv run --frozen python -m pytest tests/test_error_watch.py -q -k 'owned_dirs'` — **3 failed, 4 passed, 163 deselected**. Три положительных случая падают без шаблона, соседние ошибки остаются находками. Вывод: `red.log`.
- После исправления: `uv run --frozen python -m pytest tests/test_error_watch.py -q` — **170 passed in 10.30s**. Вывод: `green.log`.
- Новые тесты проверяют исходный отказ, обёртку ошибки хода и logger-префикс; классификацию до/после нормализации, группировку десяти повторов и исключение из post-fix повторов.
- Отрицательные случаи: ошибка лимита загрузки, она же в обёртке ошибки хода, произвольная ошибка хода и похожий текст с `no owned_dirs`, но без стабильной фразы отказа. Все остаются находками и учитываются после фикса.
- Проверено разрешение импортов `app` и `app.error_watch` в текущую рабочую копию. Абсолютные пути намеренно не включены согласно условиям задачи.
- Изменения просмотрены, проверка diff через `mask_secrets` пройдена. Временные данные тестов удалены.

Незавершённых обязательных проверок нет. Полный набор проекта и живой cron не запускались; изменение подхватит следующий самостоятельный запуск детектора.
Коммит выполняет платформа; предлагаемый заголовок: `#V-1116: classify missing owned_dirs hub guard refusal as noise`.
