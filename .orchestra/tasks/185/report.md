# #185 — навигация по чату

## Результат

- Справа от чата добавлен кликабельный таймлайн каждого отрисованного события. Цвет и ширина отличают своё сообщение, агента, воркера, инструмент, статус и ошибку.
- Кнопка `↑` без выбранной точки прыгает к последнему своему сообщению, последующие нажатия идут к предыдущим; `↓` идёт вперёд. Навигация циклическая.
- Клик и стрелки отключают автоследование за низом и отменяют отложенное восстановление позиции: стартовый таймер больше не может через 500 мс вернуть пользователя в конец поверх выбранного события.
- Таймлайн аддитивный: существующий рендер и пагинация не переписаны. `MutationObserver` обрабатывает только `addedNodes`/`removedNodes`; полного прохода по журналу на рендере нет. Сохраняется предел `MAX_CHAT_NODES = 500`.

## Браузерная приёмка

`uv run python docs/tasks/185/verify-timeline.py` подменяет `app.js`, `style.css` и фрагмент шаблона из worktree на живом `:8888`. Факт применения: один перехват каждого ассета/документа, `typeof _jumpChatTimelineUser = function`, новый `#chat-timeline` найден до проверки поведения.

Живая сессия `seedon-orchestrator` содержит 7 338 записей. В загруженной странице получено 73 кликабельных маркера, из них 4 человеческих сообщения. Клик по маркеру дал `kind=user`, целевой узел видим внутри `#chat`; кнопка `↓` сменила активный индекс `8 → 15`.

Скриншот: [chat-timeline.png](chat-timeline.png).
