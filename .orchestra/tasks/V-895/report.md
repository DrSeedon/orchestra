## Значимость и что различает такой n
- n = 8 открытых клеток на сравнение (4 задачи × 2 модели), по одному запуску на клетку: внутриклеточный разброс не измерен, клетки одной задачи для двух моделей не независимы.
- Принятое: A против B, расхождения 3/1, точный знаковый тест p=0,63; A против C: 1/0, p=1,0. Эффект в пределах шума, «тенденции» не заявляю.
- Различает такой план только разницу ≥ ~5 клеток из 8 в одну сторону (точный p<0,05 при 5–0 расхождений); при потолке A=7/8 и вовсе неразличим рост. Для вывода «B помогает» нужны задачи, на которых A принимается ≤ 50%.
- Токены: 8 пар на подвыборку; доверительные интервалы B/A целиком выше 1,2 (нижняя граница 1,29 на открытых, 1,78 на всех); это значимое удорожание. C/A: интервал включает 1 на всех, кроме Sonnet (+11%: 1,05–1,19), то есть для C рост ≤ ~20% не опровергается ни для одной подвыборки.

## Ограничения и вскрытые дефекты оракула (после запусков, решением не пользовался)

3. **Длина:** правило ≤1800 знаков отклонило B-O3-sonnet (1928) и B-O4-sonnet (2039), по содержанию правильные. Prompt требовал ≤1200; плечо B чаще нарушало формат ответа (два ответа >1800 у B против нуля у A и C; возможно побочный эффект переписывания, на 2 случаях не доказано).
Ручная пересборка по существу (не решение): A 7 (A-O1-luna верно отклонён), B 6 (−O1-luna, +O3-sonnet, +O4-sonnet), C 6. Вывод не меняется: B ≤ A, без прироста.
4. Промпт Ризеберга писался для людей и Claude; Luna в B-O2 ушла в ветку «luna идёт через harness» (неверная гипотеза о другом коде) — пример того, как «сырьё и методы» уводят от симптома.
5. Один прогон на клетку; формулировки задач мои (по симптомам из отчётов), часть симптомов подсказывает область (O4, O2). Закрытые задачи — контроль, на потолке 8/8 везде, регресс не обнаружим.
6. Инструменты Sonnet (без shell) и Luna (shell+сеть) различались; сравнивались плечи внутри модели. Luna в A/B/C ходил по разным числам ходов (54/99/66).
