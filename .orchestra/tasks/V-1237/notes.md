# V-1237 — уточнения при завершении исследования, 2026-11-02

Источник задачи — бриф Orchestra-orchestrator и последующее ограничение: продолжать только Sol, research-only, без модельного ревью и внедрения.

Запрет provider/API-вызовов и генераций относится к запуску исследуемых DSH/плагинов, а не к исследовательским LLM-ходам. Ни один плагин не прогнан; source package `app/` изучался статически, `app` не импортировался.

- Исправлена чрезмерная формулировка прошлого хода: отсутствие `importlib` не доказывает отсутствие всех видов расширений. В Orchestra есть `register_runtime`, MCP registry и восстановление MCP с повторным discovery. Не найден именно путь установки persistent bundle с UI slots и Host lifecycle в просмотренной копии; live deployment не исследовался.
- HTML preview использует sandbox iframe; видео — `<video>`, PDF — iframe без sandbox. Прежнее обобщение «видео только через sandbox iframe» неверно.
- DSH не обещает общий атомарный rollback: install/validation failure и activation/remove failure имеют разные остаточные состояния. Предыдущая версия после части HMR-сбоев не восстанавливается.
- Просмотрен скачанный ролик из публичного TG-поста, сэмплированный по кадрам. Независимая идентичность с оригинальным файлом DeepSeek не доказана. Полноценный playback/audio и воспроизведение плагинов не выполнены.
- В копии нет `.git`: commit/diff/index и результат брокерного сохранения не проверены. Публичный состав результата: `report.md`, `notes.md`, `.gitignore`; остальные evidence, скрипт и лог проверки — приватные. Проверку родительского индекса и перенос evidence в ignoredprivate выполняет принимающий оркестратор; их завершение из этой копии не подтверждено.
- Проверка первой версии отчёта: 46/47. EN-якоря ошибочно использованы на ZH-странице, где id китайские. Все семь исправлены, следующий прогон 47/47. Скрипт и лог — приватные verification evidence; это stdlib-проверка документа, не обязательный uv/pytest продукта. После редактуры публичной метадаты прогон не повторялся.
- Publication blocker найден принимающим оркестратором: публичный отчёт содержал абсолютный путь приватной worker-copy. Путь удалён, оставлен относительный `app/`; уточнены границы заявлений о генерациях, Git и доступности evidence. По этому замечанию изменены только `report.md` и `notes.md`, без новых исследований и прогонов.
