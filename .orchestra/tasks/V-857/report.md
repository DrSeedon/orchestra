# V-857 — что можно перенести из Claude Code Desktop

Исследование только по видео и действующей документации Claude Code Desktop, без реализации. Видеодорожки просмотрены по контактным листам ниже; у всех трёх роликов есть AAC audio, но локальная расшифровка Whisper Tiny не выделила речи. Скриншоты показывают UI и являются прямым доказательством того, что демонстрирует видео; механизм сверялся с документацией.

**Короткий вывод.** Механика параллельных сессий и изолированных worktree у нас уже есть. Полезные кандидаты — явные карточки с предложенными follow-up задачами, которые запускаются только по понятному действию владельца, и видимый структурированный прогресс внутри чата. Выбор Local/Cloud/SSH как у Claude — это отдельная архитектура исполнения, не перенос интерфейса. Статусы `running / waiting / idle` уже видны в dashboard; «completed» у Claude — категория списка сессий, а не прямой аналог нашего состояния агента.

## Отдельно про владельческое разрешение

Кнопка, на которую владелец сам нажал после просмотра конкретного предложения, может быть явным разрешением именно на эту задачу; формулировка должна показывать, что действие создаст задачу и запустит агента. Сам факт, что модель сформулировала follow-up, его отображение, либо запуск «Start all» без отдельного решения владельца — не разрешение. Текущий `spawn_worker` — реализационный вызов с новой дочерней сессией (`app/mcp_stdio.py:1059–1088`), а task manager привязывает таск к worker; поэтому UX-кандидат должен связать видимое подтверждение с конкретным task/project/model и текущими правилами квоты. Это рекомендация по границе авторизации, не решение об изменении контракта.

## Метод и пределы

Изучены все три переданных MP4 (длительности 17.0, 25.9 и 19.1 сек.; все видеокадры просмотрены через контактные листы; аудио обработано локальным Whisper Tiny), quickstart и релевантные разделы справочника Claude Code Desktop. Каталога `web/` в репозитории нет; dashboard-клиент находится в `app/static/` и `app/templates/`. Для локального сравнения просмотрены текущие `app/`, `app/static/`, `app/templates/`, `app/routes/` и pipeline prompts по указанным символам. Отсутствие реализации означает, что описанный механизм или UI не найден в этих путях, а не что он невозможен через произвольные инструменты агента.

Документация меняется; ссылки ведут на актуальные страницы, проверенные 15.10.2026. Оценки дней/файлов — прикидка для будущей отдельной задачи, не результат замера и не разрешение её начинать. Денежные суммы не считались, API credits не использовались.
