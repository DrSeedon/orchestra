# V-902 — AGENTS.md / CLAUDE.md сверяются платформой

## Что сделано
`app/rules_link.py`: `reconcile(root)` разбирает пару файлов, `sweep(manager)` обходит scope всех сессий, `due_for_alert` ограничивает тревоги. Фон: `Manager._periodic_rules_link` (старт + каждые 6 ч; под pytest не стартует — общий guard в `start_background_tasks`). Python: нужен рестарт, делает владелец.

Три случая из задания: симлинк → ничего; одинаковые копии или один файл → симлинк (+ локальный коммит); разные → не пишем ничего, тревога оркестратору scope. Без симлинков (`core.symlinks=false`, Windows) — точная копия. Дополнительно «ссылкой» считается `CLAUDE.md` из одной строки `@AGENTS.md` (форма, уже поддержанная `sync_agents_md`).

## Решения и обоснование
- **Когда проверять — периодически (старт + 6 ч).** Spawn/старт сессии лежат на горячем пути и коммитят в корне, пока там может идти `merge_worker` (гонка за `index.lock`); merge-хук сам правит main. Периодический обход ловит все пути, включая правки человека руками; экспозиция расхождения ограничена 6 ч. Минус: свежеспавненный воркер может до 6 ч прожить на расходящейся паре — для него есть отдельный `sync_agents_md` (зеркалит CLAUDE→AGENTS в worktree).
- **Каноничный файл.** AGENTS.md, если он обычный файл: его читают Codex и `app/harness/prompts.py` первым. Если есть только CLAUDE.md — он остаётся каноничным, AGENTS.md становится ссылкой на него: переименование стёрло бы историю файла и расширило бы дифф в чужом репо. Имена не перемещаем никогда.
- **Чистое дерево.** Правка идёт только если: оба пути не имеют незакоммиченных/неотслеживаемых изменений, HEAD на основной ветке (`resolve_base_branch`), нет MERGE_HEAD/rebase/cherry-pick/revert. Затем `git add` + `git commit --only -- <изменённый путь>` — чужой индекс и прочие файлы не затронуты; игнорируемые пути не коммитятся. Провал коммита (хук, нет user.name, index.lock) → откат обоих путей к исходным байтам и `git reset` пути, состояние `blocked` + тревога. Ни одна ветка не оставляет untracked/modified.
- **Чужой .git / другой remote.** Не пушим, remote и конфиг не трогаем, автора берём из `git config` (не задан → коммит падает → откат + тревога). Коммит локальный: ветка окажется на 1 коммит впереди upstream, публикует её владелец репозитория. Хуки репозитория не обходятся. Каталог не-git: правим на месте (грязнить нечего).
- **Тревога.** `orchestrator_for_scope` → `send` с provenance `platform/rules_link`. Состояние в `kv` (`rules_link_alert:<scope>`): повтор раз в 24 ч, сразу при смене вида проблемы, запись стирается, когда пара исправлена. Нет оркестратора → строка в журнале. Тревога пишется в kv до отправки: сбой доставки не повторится до суток (допущение, чтобы не спамить при отказе канала).

Мутации (каждая краснит именно тесты ветки): убрать проверку расхождения → 3 failed; убрать проверку ветки → 1; убрать проверку грязи → 1; убрать откат → 1; убрать проверку `if error` → 1; убрать ветку `linked_copy` → 1; запретить создание симлинка → 4.
