# Argon через Gemini Web на сервере — исследование 2026-11-05

## Запрос и подтверждённый статус

Максим сообщил, что Катя пользуется Argon в вебе с той же подпиской, и
попросил найти способ использовать такой доступ на сервере. Во время
исследования он прислал текст Google One: «Google AI Pro. Специальное
предложение от компании Jio». Происхождение подписки теперь подтверждено
пользовательским экраном; внутренний billing-флаг paid/trial отдельно не извлекался.

Это исследование возможностей. Установка клиента, перенос авторизации,
изменение Orchestra или тарифа в рамках этого запроса не выполнялись.

## Разные продукты имеют разные допуски

Официальная таблица Gemini Apps включает Argon для Google AI Pro:
https://support.google.com/gemini/answer/18648722?hl=en

У Antigravity отдельные условия paid Pro / Ultra и исключения для некоторых
trial с premium devices:
https://antigravity.google/docs/models

Следовательно, наличие Argon в Gemini Web и его отсутствие в Antigravity
на одном аккаунте не противоречат опубликованным условиям. Доступ к Argon
именно в веб-сессии Максима пока не проверен.

## Найденный серверный клиент

HanaokaYuzu/Gemini-API (`gemini_webapi`) — неофициальный Python-клиент веб-приложения:
https://github.com/HanaokaYuzu/Gemini-API

По README использует авторизованную веб-сессию Google, поддерживает диалоги
и streaming. Постоянный Chrome для HTTP-запросов не требуется; сессия может
потребовать повторного входа. Это не официальный Gemini API.

Проверен код динамического каталога моделей:
https://github.com/HanaokaYuzu/Gemini-API/blob/master/src/gemini_webapi/types/availablemodel.py
https://github.com/HanaokaYuzu/Gemini-API/blob/master/src/gemini_webapi/constants.py

Каталог и идентификаторы определяются по аккаунту при инициализации, поэтому
жёстко заданное имя Argon из Antigravity переносить в этот клиент нельзя.
README не гарантирует Argon отдельным протестированным примером. В данной
работе клиент не запускался; наличие записи в каталоге и реальный ответ
нужно подтвердить на аккаунте пользователя.

## Применение к Orchestra

Серверный доступ через такой веб-клиент технически возможен. Для Orchestra
потребуется отдельное подключение/адаптер; поиск `gemini_webapi`, `GeminiClient`,
`HanaokaYuzu` и `BardChatUi` в app/, scripts/ и pyproject.toml не нашёл существующей
интеграции. Веб-чат сам по себе не предоставляет существующий агентный
рантайм agy с его локальными shell/MCP-инструментами.

Официальный Gemini API имеет собственные проекты, API-ключи, квоты и billing:
https://ai.google.dev/gemini-api/docs/billing
Не следует считать веб-лимиты Google AI Pro автоматической квотой API.

## Предлагаемая проверка перед реализацией

Отдельно авторизовать веб-сессию пользователя, получить доступные модели,
выбрать реальный Argon и проверить один ответ с подтверждением модели.
Google описывает проверку через See response details; самоназвание модели
в тексте не является доказательством. При исчерпании лимита Gemini Apps
может переключать ответы на Flash-Lite — это также отражено в официальной справке.

На этом этапе подтверждена возможность подхода по первоисточникам, но не
работоспособность Argon на сервере с аккаунтом пользователя. Никакие
credential/cookies в исследование не копировались, серверные процессы не запускались.
