- [app/routes/sessions.py](/home/kesha/v918-work/v918-bad-cand-39.r0-sgvja19c/app/routes/sessions.py:234): проверка `If-None-Match` поддерживает только точное совпадение всей строки. По семантике HTTP заголовок может содержать список тегов, `*` или слабый тег `W/"…"`. В таких случаях сервер вернёт `200` с телом, хотя ресурс не изменился. Стоит разобрать допустимые формы заголовка и использовать слабое сравнение для GET.

Регистрация с `immediate = true` и пробуждение всех поллеров при возвращении вкладки по-прежнему запускают запросы одновременно. Поэтому решение уменьшает совпадения в обычном цикле опроса, но не устраняет начальный или повторный всплеск запросов.
