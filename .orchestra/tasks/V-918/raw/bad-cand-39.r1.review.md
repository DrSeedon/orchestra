## Summary

Проверил полный diff между указанными ревизиями. Изменения добавляют ETag и 304 для `/api/sessions` и разводят интервалы опроса.

## Findings (blocking/suggestion/question)

- **Suggestion:** `_conditional` сравнивает весь `If-None-Match` со строкой ETag. По HTTP этот заголовок может содержать `*` или список тегов; при таком запросе сервер вернёт `200` с полным телом вместо `304`. Стоит поддержать эти формы сравнения, чтобы условный запрос работал и для всех корректных клиентов.
- **Suggestion:** фазовый сдвиг действует только на повторные опросы. Поллеры по умолчанию регистрируются с `immediate = true`, а `_pollSchedule` при этом ставит таймер на 0 мс. Поэтому начальный пакет запросов остаётся синхронным; разводятся только следующие циклы.
