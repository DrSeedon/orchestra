# V-672 — компактная лента сжатия контекста

## Причина

`AgentSession.compact()` забирает tool-события чернового прохода непосредственно из `backend.events()` и пишет их через `_log(event.type, event.content)`. `_agentic_audit_summary.run_pass()` делал то же для AUDIT и FINAL. Оба пути теряли `event.metadata`, включая `tool_use_id` и `tool_name`, и не помечали строки как внутренние события компакта. Они поэтому сохранялись в `logs` как обычные `tool`/`tool_result`. Чат связывает результат с вызовом по `tool_use_id`; при отсутствующем ID он показывал «Результат без вызова».

Проверка была read-only на БД из `ORCHESTRA_DB_PATH` запущенного процесса Orchestra. Для `seedon-orchestrator`, scope `/home/kesha/projects/seedon`, строка `compact started` имеет id `488431` и время `2026-09-29T13:44:44.209394+00:00`. После неё до 13:55 UTC в `logs` записались 34 `tool_result`, все без `tool_use_id`, и ни одной строки `tool`. Это подтверждает конкретный сбой парной записи. Содержимое этих результатов не переносилось в артефакты.

## Изменения

- `compact()` и проходы AUDIT/FINAL теперь пишут `compact_event` с единым ID компакта (`event_id`), стадией, действием, исходным ID вызова, именем инструмента и результатом. Обычные `tool`/`tool_result` для этих событий больше не создаются.
- Дашборд объединяет события по ID компакта в один свёрнутый блок «Сжатие контекста». Внутри отдельные черновик, AUDIT и FINAL с вызовами и результатами, итоговая сводка, статус, проценты контекста, токены, время и цена, если данные доступны. Состояния включают «идёт», «готово», «откат на черновик» и неуспешный откат всего компакта.
- История режется по лимиту строки, поэтому очень длинный tool-результат или итоговая сводка теперь проецируются как валидный JSON с отметкой об укороченном отображении и кнопкой загрузки полного текста. В самой БД остаётся полный исходный текст.
- Старые статусы запуска/завершения и ошибки попыток компакта скрываются из обычной ленты. Telegram-мост пропускает новые `compact_event` и эти дублирующие статусы, поэтому внутренние tool-результаты там тоже не становятся обычными сообщениями.
- Сообщения и обычные записи ленты остаются самостоятельными элементами, пока карточка обновляется.
