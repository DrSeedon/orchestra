## 3. Agent API против нашего рантайма

**[П]** (`api/docs/guides/agents-api/overview`, changelog): публичная бета с 10.09.2026; управляемый Codex-харнесс на инфраструктуре OpenAI — сессии, оркестровка, компакция, восстановление; окружения: OpenAI-hosted sandbox, self_hosted, для computer use — `openai_hosted` с desktop; инструменты: MCP, web_search, programmatic_tool_calling, multi_agent (до N параллельных субагентов), навыки. Computer use добавлен 29.09: браузер в хостинге OpenAI, подтверждения доступа к сайтам и вход обрабатывает ваше приложение. Отдельной платы нет: токены по API-ставкам модели + инструменты + контейнеры (ставки контейнеров — на странице прайса).
Требует **API-ключ и оплату по токенам**, подписка Plus/Pro не покрывает.

**Что у нас [И]** (`app/backend_codex.py`, 2260 строк — Codex CLI/app-server под подпиской; `app/backend_claude.py`; `app/backend_grok.py`; `app/backend_harness.py` + `app/harness/*` — собственный агентный цикл поверх OpenRouter: bash/read/write/grep/glob + MCP, без демонов; сессии, компакция, стриминг, мид-турн стиринг уже есть в наших рантаймах). Замечание: задача #365 в этом репозитории — «доставка голоса из дашборда», а не харнесс; сопоставление сделано с `app/harness/`.

**Что даёт сверх нашего**: (а) чужая песочница и управляемое состояние сессии (не надо держать процесс), (б) computer use в облачном браузере, (в) единый API вместо запуска CLI. **Чего нет**: работа под подпиской (главная причина, по которой Orchestra держит Codex CLI), отсутствие внешней зависимости на API-квоту, свои маршруты допуска (`quota_gate`), учёт `turn_usage`.
Сколько стоит перенос **[Г]**: новый backend по протоколу `backend_protocol.py` (~500–800 строк по аналогии с `backend_harness.py` 437 строк) + ключ и бюджет. Каждый рабочий ход пошёл бы в платный API, что запрещено правилом «без слова владельца новых платных вызовов».
Вердикт: **не брать**. Возвращаться, если появится задача с облачным браузером или нужен сессионный сервис без своей машины; у нас VPS.

## 4. Decisions API против Jev/TypeSafe

**Decisions API [В]** (The New Stack, The Decoder, byteiota; страницы доков нет — `developers.openai.com/api/docs/guides/decisions*` дают 404; в `api/docs/changelog` и `llms.txt` упоминаний нет): вход — контекст (текст/картинка), вопрос, конечный набор ответов; выход — один ответ + confidence, придумать новый ответ нельзя; специализированный вариант GPT-6 Luna; ~150 мс против 1,6 с у обычной Luna (Decoder), «76 из 78 шагов при ~230 мс» на симуляции компьютерных задач (byteiota, не подтверждено). **Цена не объявлена**, лимитов на число вариантов нет, статус — limited preview, «общий релиз в ближайшие дни».

**Jev у нас [И]** (`TODO.md` разведка 19.09, `V-98/report.md` в seedon 28.09): `POST https://api.typesafe.ai/v1/systemone`, ключ владельца в `.env`; $0,042 за 1М входных токенов, выход бесплатен; V-98: 50 `choice`-вызовов, 55 630 входных токенов, 12,9 с суммарно (**≈258 мс/вызов**), ≈$0,0045 за весь прогон; живая проверка 19.09: медиана 257 мс.
- В классификаторе закупок seedon Jev **не в проде**: V-98 — замер поверх детерминированных правил. Правила сняли 20 из 33 «нет» без потери «да»/«проверить» (0/17); Jev с порогом `choice=нет & conf≥0,5` убрал ещё 7 из 13 оставшихся «нет» и тоже не задел «да»/«проверить» на этой выборке из 50 закупок. Решение включать — за владельцем.
- Для Orchestra: сторож зацикливания (2548 вызовов/сут), разбор сообщения владельца (458/сут), маршрут модели при спавне (7/сут) — потенциальные точки применения, суммарно ≈$3,55/мес при Jev; внедрения нет.

**Сопоставление**: задержка сопоставима (150 мс заявлено против 258 мс замерено — числа из разных условий, сравнивать нельзя); цена Decisions неизвестна, у Jev $0,042/1М входа против $0,10/1М входа у самой Luna — если Decisions API будет по ставке Luna, он в ~2,4 раза дороже Jev за вход (это **допущение**), но объёмы у нас крошечные (десятые доли цента в сутки), поэтому цена не решает; преимущество Decisions — картинки на входе и единый поставщик; у seedon текст, картинок нет. Риск — превью, нет доков, нет цены. Также API-оплата, а не подписка.
Вердикт: **не брать сейчас; вернуться после общего релиза и публикации цены**, если решим включать сторож или разбор сообщений — тогда сделать A/B на тех же 50 закупках из V-98 (уже размечены) плюс сторож на выборке из 2548 вызовов.
