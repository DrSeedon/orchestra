# V-1082 — Telegram /limits: история каждого окна

Реализованы шесть графиков: Claude 5h/7d, Codex primary/secondary, Spark primary и Grok primary. Сохранены ширина 900 px, тёмная палитра, недельная сводка и её арифметика. Код `tg_bridge.py`, подписи, первая доставка фото, сохранение message_id и обновление существующего сообщения не изменены. CHANGELOG дополнен вручную.

Источник — существующие `usage_snapshots` и тот же выборщик, что обслуживает `/api/usage/history`: 168 часов, шаг 30 минут, свежие 48 часов с шагом 5 минут. Синхронная часть endpoint вынесена в `usage_history_data`; API сохраняет async-интерфейс и owner guard. PNG читает её в потоке с бюджетом 3 секунды. При исключении/таймауте сохраняются сама карточка и текущие числа, вместо графика показывается недоступность истории. Уже начатое чтение SQLite может закончиться после таймаута; ожидание карточки его не дожидается.

Важная находка: канонический выборщик переносит последнее значение на сетку до двух шагов. В возвращаемую строку добавлен `sample_ts` — исходное время снимка, без миграции/нового хранилища. PNG удаляет повторы по этому времени. Старые ответы без поля принимаются по `ts`; старые Claude-only колонки не создают историю других провайдеров. Фронтенд продолжает использовать свой `ts`, его поведение не менялось.

Выбор периода повторяет `usage.js`: якорь — самая длинная серия провайдера, последний период с ≥2 измерениями, обрезанный началом окна из reset−duration; короткие серии используют общие границы якоря. Если такого периода вообще нет, отдельный снимок показан точкой. Погрешность reset до часа остаётся тем же периодом. Внутри графика смена reset более чем на час, смена длительности, пропуск окна в имеющемся снимке и промежуток более 1.5 шага разрывают линии. Стрелок навигации в статическом PNG нет.

Y — явно подписанные 0–100%, X — фактическое время UTC+7. Пунктир означает прошедшую долю окна; без reset он не рисуется. Отсутствующие, булевы, нечисловые и невалидные проценты не превращаются в ноль; измеренный 0 остаётся данными. Последнее значение подписано своим временем; старое помечается устаревшим и не продлевается до настоящего момента. Недельный пересчёт числа доступных окон сохранён как сводка: исторического ряда этого производного коэффициента канонический источник не содержит.
