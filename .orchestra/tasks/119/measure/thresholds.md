# Пороги #119 — зафиксированы ДО правки скилла и ДО прогона «после»

Коммит этого файла предшествует любой правке `html-artifacts.md`. Пороги после прогона
не двигаются: если «после» их не берёт — это отрицательный результат, а не повод переписать порог.

## Измеренный шум (пилот, 4 независимые сессии, скилл НЕ менялся)

P1 (пост-мортем) ×2 и P2 (сравнение) ×2, разные жанры, разные сессии:

```
файл                           акцент     hue кегли загл   M3   M4   M5   M6
P1-run1.html                   #7c3aed    262     8    3   ok    —   ok    —
P1-run2.html                   #7c3aed    262     6    3   ok    —   ok    —
P2-run1.html                   #7c3aed    262    12    3   ok   ok   ok    —
P2-run2.html                   #7c3aed    262    11    3   ok   ok   ok    —

M1 уникальных акцентов : 1 из 4
M2 фиолетовых          : 4 из 4
M6 @media print        : 0 из 4
```

| Метрика | Собственный шум метрики | Комментарий |
|---|---|---|
| M1 акценты | **0** — 4 из 4 дали ровно `#7c3aed` | акцент не пляшет вообще: он взят из скилла, а не выбран |
| M2 фиолетовый | **0** — 4 из 4 в полосе 235–295 | |
| M6 печать | **0** — 0 из 4 | нынешний скилл про печать не говорит |
| кегли (не метрика) | 6–12, разброс есть | объём вёрстки шумит, иерархия — нет |

**Шум по трём дискриминирующим метрикам равен нулю.** Поэтому любой сдвиг по ним превышает
шум по построению, и вопрос порога — не «отличить эффект от шума», а «достаточен ли эффект,
чтобы его стоило внедрять».

| M1 | уникальных акцентов | 1 из 4 | **≥ 4 из 5** | прирост |
| M2 | фиолетовых (H 235–295) | 4 из 4 | **≤ 1 из 5** | прирост |
| M6 | `@media print` | 0 из 4 | **5 из 5** | прирост, обязателен по AC T2 |
| M3 | типографская иерархия | **2 из 4** | **5 из 5** | **прирост** (см. правку ниже) |
| M4 | `:focus-visible` там, где есть контролы | **1 из 3** | **все интерактивные** | **прирост** (см. правку ниже) |

Дискриминирующих метрик **пять**: M1, M2, M3, M4, M6. Чистый регресс-гард один — M5.

### Правка пререгистрации, 05.08.2026, ДО начала T2 и ДО любой правки скилла

Первая редакция этого файла ставила M3 «baseline 4 из 4» и M4 «2 из 2», обе — «регресс-гард,
прирост показать не может». **Это неверно, исправлено.**

- **Причина ошибки:** те числа взяты из ПИЛОТА, а пилот — это только два жанра (P1 пост-мортем,
  P2 сравнение), где обе метрики зелёные. На полном наборе дашборд (P3) и схема (P4) валят и M3,
  и M4. Пилот честно померил шум M1 (там все 4 прогона совпали), но обобщать с него на M3/M4
  было нельзя.
- **Что изменилось:** baseline-числа и роль M3/M4 (регресс-гард → прирост). Целевые пороги
  для них — те же, что стояли (5 из 5 и «все интерактивные»), их я не трогал.
- **Что НЕ изменилось:** M1, M2, M6, M5 — пороги и роли ровно те же, что утверждены.
- Числа baseline сняты по 4 собранным артефактам из 5; P5 (план) на момент правки ещё считался
  и в таблицу войдёт последним. Пороги «после» от него не зависят и заданы окончательно.

Правка внесена отдельным коммитом до правки скилла — чтобы порядок «пороги → правка» читался
в истории. Молча отредактированная пререгистрация ничем не отличается от порога, подогнанного
задним числом.

### Оговорка к M1: разнообразие обязано следовать из предмета

Пять случайных цветов берут порог M1 и не решают задачу — это замена «всегда фиолетовый»
на «всегда лотерея». Поэтому в отчёте по каждому из пяти артефактов приводится строка
**задание → выбранный акцент → чем обоснован**. Если связка не читается, исход записывается
как «метрика зелёная, результат отрицательный», а не как успех.

### Что baseline показал содержательно (важнее самих метрик)

`calc`/`var` в `font-size` — **0 из 4 артефактов**. Выведенной типографской шкалы не строит
никто; M3 на baseline проходит исключительно за счёт третьего уровня заголовка (`<h3>` есть
в P1 и P2, нет в P3 и P4). То есть дефицит не «мало токенов», а **отсутствие шкалы как приёма**.

### Как читается исход

- **M5 провален** → правка откатывается независимо от всего остального.
- **M1 ≥ 4, M2 ≤ 1, M6 = 5, гарды целы** → правка принимается.
- **M1 = 2–3** → эффект выше шума, но слабый: фиксируется как «сдвинулось, но не решило»,
  решение о внедрении принимает оркестратор. Порог задним числом не смягчается.
- **M1 = 1** → правка не работает. Отрицательный результат, откат.

## Оговорка про сам стенд

M1 в первой редакции считала самый частый насыщенный цвет и на пилоте показала «2 разных
акцента из 2» — то есть ровно тот сигнал, по которому задачу следовало остановить. Сверка
с сырыми файлами показала, что оба артефакта объявляют один и тот же `--accent: #7c3aed`,
а различались частоты статусных цветов. Метрика переписана на объявленный токен и проверена
мутацией. **Числа выше сняты уже исправленной версией.**
