# #260 — понятные и корректные карточки инструментов

## Результат

P0 исправляет смысловую ошибку: результат параллельного вызова теперь связывается
с карточкой только по точному `tool_use_id` в normal и compact mode. Старый fallback
«к последнему вызову» удалён. Непарный результат не теряется и не маскируется — он
виден отдельной строкой `Результат без вызова`.

P1 меняет только операционные результаты задач и списков агентов:

- задача начинается с действия `Задача #260 создана`, затем показывает статус,
  проект, приоритет и описание; нулевая цена не занимает место;
- список агентов начинается с `N всего`, числа работающих / ожидающих / сломанных и
  отдельной строки тех, кто требует внимания;
- исходный JSON или текст не выброшен — он закрыт в `Технические детали`;
- compact mode даёт краткую сводку в строке, а по клику открывает ту же полную
  карточку с техническими деталями.

P2 (фильтры внимания) и P3 (свёртка lifecycle) не реализованы — они остановлены до
отдельного решения после показа P0+P1 пользователю.
