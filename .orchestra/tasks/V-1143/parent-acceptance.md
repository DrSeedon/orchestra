## Why the security findings change the verdict

P1 proves untrusted command-path text reaches a learned fact, but does not prove a real model obeyed injected instructions. P1 also bounds a regex stall, not arbitrary code execution. P3 and direct source state.py187–190 prove that a fake Authorization token remains in recent command text supplied to the judge/writer. This is not an actual secret leak in our experiment: all data synthetic and provider binaries absent. It disproves treating an upstream digest as automatically safe to send elsewhere. Local retention and publication protections must remain; no protected live traces went to the worker.

Plugin loopguard never stops the agent: its internal abort action is rendered only as a notice. Paper's abort savings cannot be inherited. Native headless notices may be invisible and remote hub hooks cannot be installed from this local client. Any proposal should begin with non-mutating observations and explicit authority, not global plugin installation.

Decision proposed to owner: first a bounded model-free offline candidate/measurement prototype for operational facts and actual tool surface, after approval. No implementation task or branch created.
