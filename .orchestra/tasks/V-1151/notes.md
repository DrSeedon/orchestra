# V-1151 — findings

- `scope` routes a worker to its orchestrator/DB namespace. It is not necessarily the worker's Git repository. The synthetic parent and its nested source repository have independent `.git` directories.
- The first round found a separate context bug for rows without `worktree_path`. It did not reproduce the reported linked worker: the parent established that its `worktree_path == cwd`. Retain the `cwd` fallback as a secondary fix, not as proof of the reported case.
- The reported shape is now reproduced with a real independent reports-only base and linked worker containing exactly ordinary `tasks/` and `private/` directories under `.orchestra`, without layout in either. The original memory-state predicate treats private as managed memory, so the actual ownership route returns HTTP500 even with correct repository context.
- Ordinary private directories contain output artifacts, not project memory. Exempt only that exact directory entry, as with task reports, without reading private contents. Files and symlinks at `private`, unknown entries, journals, layout markers and actual managed state still refuse. Both the linked checkout and its own base remain checked.
- `allow_missing_layout`, migration, HTTP/MCP outcome classification, admission and ownership transaction/locks remain unchanged. The real migration function is a forbidden-call sentinel in positive tests. Existing private bytes, internal links, root ignore rules and Git common `info/exclude` are snapshot-tested.
- The regression seeds existing session rows, exercises loaded registration and real detached hydration, then invokes the real MCP adapter, HTTP ownership route, manager and SQLite persistence. Synthetic Git/source/report/memory contents are real; provider startup is a failing sentinel.
- Synthetic snapshots cover refs, worktree registry, stashes, tracked/untracked file and symlink contents, session columns, task rows and reservations. Reports and ordinary root `skills/` are source inputs, not evidence of managed memory.
- No child agent, reporter project, live log/session, provider, credential or service action is needed. V-1130's historical report is read-only context.
- Test shells put `/usr/bin` after the provisioned uv directory and before the inherited dispatcher shims, so synthetic Git operations execute locally. An initial 30-second test timeout expired during Pydantic import, not in a behavioral assertion; accepted runs use a 180-second hang bound, without treating it as a performance measurement.
- `LayoutMigrationError` deliberately names the Git main checkout as its repair target for a linked worker. Negative controls must assert that source project's main path, not the linked checkout or the orchestrator's unrelated scope.
