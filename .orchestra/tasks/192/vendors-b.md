# Таблица фактов: российские CDN, группа B

Собрано 20.08.2026. Только факты из первоисточников, открытых в этой сессии. Выводов, рекомендаций и ранжирования нет по условию задачи.

**Профиль расчёта (задан постановкой):** 50 ГБ исходящего трафика в месяц + 2 домена.

**Как добывались страницы (существенно для воспроизводимости):**
- Ngenix и Servicepipe отдают анти-бот challenge на `curl`, `WebFetch` и `r.jina.ai` (503 / «Доступ временно ограничен» / JS-challenge Servicepipe). Обе открыты через headless Chromium (Playwright), который проходит challenge. Скрипты рендера: `/tmp/fetch_pw.py`, `/tmp/nav_pw.py`, `/tmp/ng_row.py`.
- `servicepipe.ru` — SPA: прямой заход на `/pricing` даёт 404, страница открывается только клиентской навигацией с главной.
- Наш egress по умолчанию идёт через прокси с немецким IP; для российских сайтов запросы делались с `--noproxy '*'`.
- Значения «да/нет» в таблице сравнения тарифов Ngenix сняты из отрендеренного DOM (галочка/крест), а не из HTML-эвристики: два текстовых способа дали противоречащие результаты, DOM-чтение выбрано как разрешающее.
