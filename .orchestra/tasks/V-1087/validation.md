1. В текущих официальных документах множители Claude относятся к сессии; перенос четырёхкратного отношения на недельный лимит не подтверждён. Точные cache-коэффициенты подписки не опубликованы; API-equivalent USD не заменяет подписочный расход.
2. Старый поисковый snippet Code содержит 225/900 сообщений и Opus 4 fallback 20%/50%; открытая текущая статья этих гарантий не содержит. Не переносить их из старых заметок.
3. Free Codex включён, но модель/поверхности описаны несогласованно: текущий developer pricing перенаправляет на Learn и указывает Luna desktop subject to rollout, другая pricing-страница сохраняет Terra desktop. Cloud прямо исключён из Free/Go. Работоспособность конкретного CLI-маршрута нельзя обещать по общей рекламе Free.
4. Текущая документация Max публикует отдельные monthly API credits $100/$200; их нельзя расходовать в интерактивном Code или использовать для пополнения подписочных лимитов. Это публичный benefit, не доказательство конкретного баланса или его получения нашим аккаунтом.
5. Справка GPTs сейчас запрещает создание/публикацию новых GPTs на всех personal plans, включая Plus. Это не новая потеря именно от downgrade.
6. Старое описание ChatGPT cancellation «day after next billing date» в поиске расходится с открытым текущим «end of current billing period». В отчёте использована текущая редакция; точное время завершения доступа остаётся локальным фактом.
