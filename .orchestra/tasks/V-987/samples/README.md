# Образцы Voxtral 3

Аудиофайлов нет. На 20.10.2026 в публичном каталоге Mistral не обнаружены открытые веса Voxtral 3 для русского ASR/TTS. Публичная Voxtral TTS 4B (CC BY-NC 4.0) не поддерживает русский и её официальная карта требует GPU от 16 ГБ; новая Voxtral Mini TTS 3 и Transcribe 3 доступны в статье как hosted модели, но публичные веса не найдены. Русская озвучка и ASR пяти фраз V-892 потребовали бы платного Mistral API, который не вызывался.

При тарифах статьи предполагаемый один прогон: 724 символа × $13/1M = $0.009412 за TTS; 45.55 секунды × $0.0035/мин = $0.002657 за ASR (45.55 с — длительность Tera-примера V-892, поэтому сумма ориентировочная). Всего около $0.0121, без возможной отдельной стоимости Pro Voice.
