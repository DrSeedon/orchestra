ПРЕДМЕТ РЕВЬЮ: техническое решение перед внедрением.

## Задача

Сервис на Python пишет события в SQLite. База работает в режиме WAL, запись идёт постоянно.
Нужно снять с работающей базы снимок, чтобы приложить его к разбору инцидента как
доказательство: в снимке обязана быть строка, записанная за секунды до снятия.

## Предлагаемое решение

Не копировать файл базы через `cp` или `shutil.copy`: при WAL самые свежие транзакции лежат
в файле `-wal` рядом, ещё не перенесённые в основной файл. Копия основного файла отдаст
устаревший срез, и в разборе это будет выглядеть как «события не было».

Снимать через штатное API SQLite — `sqlite3.Connection.backup(dst)`. Оно проходит по страницам
базы под нужными блокировками и отдаёт согласованный снимок, включающий свежие транзакции.
Ставим этим же соединением, отдельный файл назначения, никаких внешних утилит.
