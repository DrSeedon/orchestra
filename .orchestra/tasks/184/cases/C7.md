## Задача

Менеджер задач запускает долгие дочерние процессы (`sh -c "..."`), каждый в своей группе
процессов, чтобы потом гарантированно убить всё дерево — сам процесс и всё, что он породил.

## Код

```python
def spawn(self, cmd: str) -> Job:
    proc = subprocess.Popen(cmd, shell=True, start_new_session=True)
    job = Job(proc=proc, pgid=os.getpgid(proc.pid))
    self._jobs[job.id] = job
    return job

def cleanup(self, job_id: str) -> None:
    job = self._jobs.pop(job_id, None)
    if job is None:
        return
    try:
        os.killpg(job.pgid, signal.SIGKILL)
    except ProcessLookupError:
        pass
```

`cleanup` вызывается по таймауту задачи, по отмене пользователем и из периодической уборки
раз в минуту — то есть может быть вызван и через заметное время после того, как процесс
завершился сам.
