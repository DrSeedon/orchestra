Источник: `cli-tool/src/index.js` (https://raw.githubusercontent.com/davila7/claude-code-templates/main/cli-tool/src/index.js), `installIndividualSkill`:
- берёт `category/name`, **качает по GitHub contents API с ветки `main` без пина ref** (`.../contents/cli-tool/components/skills/${skillName}`), затем каждый файл по `download_url`;
- пишет в `<cwd>/.claude/skills/brainstorming/…` (категория отбрасывается), `--directory` меняет базу; `.py/.sh` получают chmod 755 (у этого skill их нет);
- требует `SKILL.md`, иначе failure;
- telemetry: `trackDownload` POST на `https://www.aitmpl.com/api/track-download-supabase` с `type,name,path,category,cliVersion` (path = каталог установки!), плюс `trackInstallationOutcome` (там по описанию уходят Node-версия, platform, arch). Отключается `CCT_NO_TRACKING=true`/`CCT_NO_ANALYTICS=true`/`CI=true`; флага CLI нет (https://raw.githubusercontent.com/davila7/claude-code-templates/main/cli-tool/src/tracking-service.js). Пересказ про «IP не собирается» относится к коду клиента; сервер IP видит всегда.
- Вне `.claude/skills/` команда ничего не меняет, если не заданы settings/hooks/loop-флаги.
Итого: поставить можно и без npx — это ровно 3 файла из публичного дерева, значение в тексте, а не в CLI.

## 4. Риски и ограничения
1. **Supply chain:** `@latest` + `main` без пина = содержимое skill может измениться между установками (подтверждено: изменилось 2026-11-01). Текст skill — это инструкции агенту (prompt injection surface). Бот-проверка PR: SkillSpector `--no-llm` score 0 (самоотчёт PR); общий security-audit репозитория «FAILED 395/770 компонентов» (по тому же PR) — для нашего skill не относится, но показывает качество каталога.
2. **Telemetry на внешний сервис** с путём каталога установки; на хабе это `/mnt/claude-data/...` — путь пользователя. Нарушает дух «никаких private данных наружу»; запускать на хабе не нужно.
3. **Тесты автора — headless `claude -p`** на нескольких сценариях (самоотчёт PR), не измерение эффекта. Утверждений «лучше результат на X %» в источниках нет.
4. **Триггер skill агрессивный:** description «You MUST use this before any creative or build work… skip only for fully specified one-line tasks» + `<HARD-GATE>` «nothing gets built until the user approves the design doc» (SKILL.md). В нашей среде это прямое столкновение с правилами (см. §5).
5. Поставка в чужой каталог `.claude/skills/` — для Claude Code; Orchestra сама раздаёт skills в worktree (app/prompting.py:338-523), так что ставить через npx в наш репозиторий не только не нужно, но и создаст конфликт владельцев файла (prompting.py:357-359: tracked `<home>/skills/<name>/SKILL.md` считается принадлежащим репо).
