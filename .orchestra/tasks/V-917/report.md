# V-917 — светлый «бумажный» стиль по умолчанию в инструменте роликов

Решение владельца 17.10.2026 после демо V-912. Анализ стиля и прежние демо лежат в `.orchestra/tasks/V-904/`.

## Что сделано
- `scripts/video_artifact/make.py`: добавлен ключ `--theme paper|dark`, по умолчанию paper; файлы тем — `video-paper.css` и `video-dark.css` (бывший `video.css`).
  После каждого `P.seek` вызывается `Paper.chrome`: он рисует полосу прогресса и размывает субтитр при смене (`SEEK_JS`).
  Тема передаётся Manim через `VIDEO_ARTIFACT_THEME`: `manim_voice.py` берёт оттуда палитру, а шрифт Manrope на бумаге, CMU Serif в dark.
- `scripts/video_artifact/paper.js`: `install`, `picture` (рваный край, зерно, виньетка, дрожание линий), `brush`, `camera`, `miniature`, `fade`, `type`, `chrome`. Все функции чистые по `t`; make.py вставляет файл до запуска сцены.
- Звук. В `sfx.py` добавлен тип `bed`: запись берётся целиком, начало обрезается по `trim_s`. В `library.json` внесена «Long Ambient Pad» (indigo.cloud, CC0, Freesound 254856, `trim_s: 2`) как bed по умолчанию.
  Сборщик подмешивает её, если не указаны `--music`/`--no-music`. Повтор подложки идёт с перекрёстным затуханием 1 с (`mix.py`).
  Под музыкой между фразами нет тишины, поэтому начала фраз ищутся по голосовой дорожке микса, а совпадение микса с MP4 проверяет qa.py.
  Набор звуков на VPS пересобран (`sfx.py kit`): 1140 звуков в 20 типах, `bed` — 1 запись; количества в прежних типах не изменились.
- Скилл `video-artifact.md`: новый раздел «Paper style (default)» с решением владельца, правилами стиля и API комплекта; обновлены разделы о звуке и Manim.
  `explainer-craft` не трогал: это личный скилл вне репозитория, правила стиля целиком в video-artifact.
