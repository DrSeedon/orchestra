## 1. Что скиллы делают на самом деле

### anatomy (wheresryan22)
- **Что это.** Скилл Claude Code для «изометрической SVG-фигуры, которая объясняет идею как реальный физический предмет» (SKILL.md, строки 1–25). Стек: Node ≥20.10 + Chrome для проверок; `kit/iso-kit.mjs` (~одним файлом: камера, solids, SVG-рендер строкой, карточка `Fig n` с заголовком, подсказкой и «живым» числом), `kit/lathe.mjs`, `kit/tube.mjs`, `kit/audit.mjs` (проверка геометрии: пересечения, порядок рисования), `kit/gl.mjs` (WebGL-слой между задним и передним SVG для огня, воды, света), `kit/turn*.mjs` («3D-режим», в SKILL/3d.md честно помечен **beta**). Вывод — одна HTML-страница или React-компонент. Всего ≈20 тыс. строк JS/TS.
- **Как строится «3D».** Это не движок сцены: детали рисуются как проекция в одну изометрическую камеру painter's-алгоритмом, порядок слоёв доказывается лучевой проверкой (`audit.mjs`). «3D-режим» — жёсткие группы (`turn`, `slide`, `hinge`, `free`), которые перепроецируются каждый кадр; в `references/3d.md` — пример: комбинационный диск с рукой-роботом. Физики в смысле моделирования столкновений нет: «модель» — это маленький чистый модуль формул (`rig.ts`, `model.mjs`; в ripple-tank — дисперсия и оптика воды), от которого зависят число на экране и движение. Правила качества: 40–150 деталей на фигуру, «аудит до нуля», проверки 4× zoom, `scripts/lines.mjs`.
- **Привязка к фото: нет.** По репозиторию поиск `reproject|photogramm|solvePnP|camera solve|cannon|rapier|verlet` — ноль попаданий в коде (совпадения «physic|rigid» — только слова про жёсткие группы в 3d.md/turn-audit). Слово «photo» встречается лишь как «фотостудия» в таблице идей.
- **Видео: нет.** Поиск `ffmpeg|.mp4|screencast|recordVideo` по всем не-HTML файлам — 0. Есть только скриншоты и `drive.mjs` (сценарий в headless Chrome, контактные листы, замедление `["slow", 0.05]`).
- **Звук, речь: нет.**
- **Лицензия:** MIT. Есть путь публикации в галерею `wheresryan22/anatomy-community` (`references/publish.md`) — отправка только по явному «да» пользователя; нам этот путь не нужен.
- **Цена генерации по их же оценке:** «Figure» ~≤1 ч, «Hero» 2–4 ч, «Epic» 6+ ч (SKILL.md, шаг 1).

### opus-sound-layer (Bodila51)
- **Что это.** Не озвучка речью. Это **звуковые эффекты и микс**: «Opus не слышит, поэтому его синтетические звуки мимо картинки — дадим настоящие записи, микшер, QA» (README). Три скрипта на Python (`uv run`, зависимости numpy/scipy/soundfile/matplotlib/pyloudnorm) + `library.json` с манифестом:
  - `sfx.py kit` скачивает 7 пакетов Kenney и записи Freesound, режет по событиям, фильтрует, судит (гулкие/шипящие/мягкая атака отбрасываются), получает **1 139 звуков в 19 типах** (hit, boom, riser, reverse, whoosh, thump…). `browse` ранжирует по тегам/длине/яркости и рисует осциллограммы и спектрограммы, чтобы агент «увидел» звук; `search/add` ищет через Openverse (только `license=cc0`) без ключа.
  - `mix.py` строит микс из одной cue-sheet (`frame`/`t`, тип/id/файл звука, `weight: hero|support`, `align`, `visual: cut|move|land`): пик звука на кадре события, gain на каждое событие решается в собственной полосе против «музыка+голос», общая «комната» (реверб 0,6 с), ducking музыки под голосом, «мёртвая пауза» и high-pass-нарастание перед hero-ударом, мастер −14/−18 LUFS и true-peak лимитер −2 dBTP. **Голос принимается готовой дорожкой** (`voice: [{file, start_s}]`).
  - `qa.py` проверяет уже закодированный MP4: смещение, громкость, true peak, каждый cue против реального движения в картинке (`cut/move/land`), слышимость, тишину. Выход ≠0 при провале.
- **TTS: нет ни локального, ни платного.** Видно и по звуку роликов из поста (ниже). Платных API нет; Openverse/Freesound — бесплатные, без ключа.
- **Лицензия:** код MIT; звуки CC0 (в `CREDITS.md`, собранном нашим прогоном, 839 строк, все «CC0»). Звуки в репозитории не лежат — скачиваются.
- **Спорный пункт, проверен:** `PROMPT.md` (44 строки) — это тот самый текст для вставки в Claude Code; он запрещает синтезировать удары/клики/вжики («Never synthesize hits, clicks or whooshes») и требует «выбирай каждый звук сам, смотри на спектрограмму, не называй звук хорошим — отчитайся по проверкам, на слух проверяет человек».

### Что на самом деле стоит за роликами (вывод по кадрам и звуку)
Ролики: `hindenburg_midcrash_small.mp4` 35 с, `crash_at_crush_simulation_small.mp4` 84 с (Texas, 1896), `tu124_neva_1963_small.mp4` 120,6 с; все 1080×1080, 30 к/с, H.264 + AAC 48 кГц стерео.
- **Оформление** — карточка `Fig n` / заголовок справа / подпись снизу / живое число справа внизу: совпадает с рамкой анатомии (гипотеза по сходству кадров; код роликов мы не видели → ярус 4). Тёмная схема, тонкие контурные 3D-модели.
- **Фото ↔ модель.** Кадры crash-ролика прямо подписаны: «Camera solved from the plate: 62 m west of the track, lens 2.8 m above the rail · reprojection error 1.6 px»; «simulated end state vs. Deane's plate · camera fit 1.0 px / 0.5 px»; «crush strengths fitted to the photographs»; «each launch is solved backwards, with air drag, from where witnesses found the piece»; в TU-124 — восстановление положения корпуса под водой «по снимку». Это решение обратной задачи (калибровка камеры по опорным точкам фото, подгонка параметров симуляции под кадр) — своя математика агента; **ни в anatomy, ни в sound-layer её нет.**
- **Физика** — своя, по подписям: энергия контакта 43,7 МДж, разброс обломков с сопротивлением воздуха, торможение 1,2 g, спуск 12° — расчёты агента, не скилл. Анатомия лишь задаёт стиль «числа на экране из той же модели, что двигает детали».
- **Звук.** `volumedetect`: средний −20,2 / −20,7 / −22,9 дБ, пик −1,8…−1,5 дБ; спектрограмма Hindenburg (`frames/hindenburg_midcrash_small-spec.png`): постоянный низкий гул + отдельные вертикальные широкополосные удары, **формант речи нет**. Субтитров-подписей достаточно для смысла: **речи (TTS) в этих роликах нет** — текст на экране. Deepgram не вызывался (платный; для вывода хватило спектра).
**Поправка оркестратора 13.10 (после вопроса владельца):** вывод верен только для двух роликов. Deepgram nova-2 по всем трём: hindenburg и crash — пустая расшифровка, а в **tu124_neva_1963 есть русская закадровая речь** («Через 4 минуты правой тяги больше нет… Все 52 человека выходят по крылу… никто не погиб»). Чем она синтезирована, не установлено; в sound-layer и anatomy TTS нет — голос автор делал отдельно. Спектрограмму смотрели только у Hindenburg, отсюда ошибка обобщения.
- **Длительность/вес:** 20–55 МБ на 35–120 с.

## 4. Чего наш стек не умеет по сравнению с их роликами

1. **Звук поверх картинки.** У нас голос и ничего больше; у них постоянный гул и удары на событиях с синхронизацией по кадру (проверено спектрограммой). Закрывается sound-layer (п.3).
2. **Сравнение модели с историческим снимком**: врезка архивного кадра, поверх него контур модели, подпись «reprojection error 0.5–1.6 px». Нет ни привязки камеры, ни такого монтажа.
3. **Подгонка расчёта под свидетельства** (энергия контакта, траектория обломков «назад» от мест найденных осколков, глиссада 12°). Общего симулятора нет; V-170 — анимация по заданной траектории, не расчёт.
4. **Самостоятельный сбор источников** (поиск реальных фото события агентом). Это поведение сессии Opus с веб-доступом, а не скилл; у нас оно не зафиксировано как процедура и не проверено на лицензиях изображений (исторические фото могут быть не public domain).
5. **Квадратный 1080×1080 для Telegram и плотная «информационная» вёрстка** — у нас 16:9; формат решается параметром, не пробел.

Что у нас **лучше**: локальная русская озвучка с ударениями и проверкой распознаванием; проверенный сценарий ожидания ролика под телефон (субтитры, кегль ≥15); измеренная модель-матрица для 3D-роликов (Sonnet/Opus годятся, Luna нет — V-731); готовая цепочка Chromium+TTS+mux в `make.py`.

## 6. Ограничения и непроверенное
- Пост получен пересказом (инструмент вернул резюме, а не дословный текст); состав роликов — по самим файлам.
- Какой именно рендерер у роликов (anatomy `turn`, свой three.js или Canvas), не установлено: исходников сессии автора нет. Утверждение «рамка совпадает с анатомией» — по сходству кадров.
- Качество звука на слух не оценено (агент не слышит); спектрограмма показывает структуру (гул + удары), не вкус.
- Цены переноса — оценки по аналогам V-731/V-723, не замеры.
