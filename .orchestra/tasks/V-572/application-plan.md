# Применение личных указателей

Канон и его подключение к ролям принимаются обычным merge. Затем полномочный
оркестратор после одобрения заменяет оба личных SKILL.md предложенными указателями.
Воркер внешние файлы не редактирует.

До каждой замены сверить SHA текущего источника с sources.json; при изменении
пересобрать diff, а не перетирать чужую правку. Сделать копию оригинала РЯДОМ с ним
с уникальным суффиксом V-572/времени, сохранив owner/mode; записать backup-пути.
Новый указатель записать временным файлом рядом и заменить атомарным rename.
Проверить, что оба тела равны предложенным и канонический путь после merge существует.
Если второй шаг не удался, вернуть первый файл из backup: это пакет, не атомарная
транзакция двух путей. Откат возвращает оба оригинала с их метаданными.

Не менять другие личные скиллы, ключи, SSH-конфиги, туннель или службы. После замены
внешних файлов не объявлять каждую открытую сессию обновлённой без проверки её
фактического перечитывания. Рестарт Orchestra в этой задаче не разрешён.
