# V-891 — русская озвучка: что уже решено, рынок на 16.10.2026, цена 20-минутного ролика

Только исследование. Платные API не вызывались, аккаунты не создавались, локальные модели не скачивались.
Цены сверены 16.10.2026 по страницам вендоров, кроме отмеченных «по V-18»: эти цифры University проверил 14.10.2026, сегодня страница их не отдала.
**Качество звука я не слушал.** Все оценки качества взяты из описаний вендоров или из отзывов и помечены так.

## Коротко

- **TeraTTS оставляем основным голосом.** Платная озвучка 20-минутной лекции стоит от **$0,14 до $1,40**, премиум ElevenLabs — **$1,12**. Деньги здесь ничего не решают. Вопрос только в том, звучит ли платный голос заметно лучше, и ответить на него может лишь слепое прослушивание. Такого прослушивания у нас ещё не было ни разу (V-18, V-694, V-852).
- **Лучший дешёвый качественный вариант для нашего тракта — Yandex SpeechKit**, около **$0,22–0,26 за ролик**. Он платится в рублях, физлица из РФ подключаются. Это единственный облачный сервис, который понимает **нашу же разметку**: `+` перед ударной гласной и `sil<[мс]>` для паузы. Ручные правки ударений из сценариев переносятся без переделки. Качество русского голоса известно только со слов вендора.
- **Второй кандидат на пробу — Gemini 3.8 Flash TTS**: около **$0,28 за ролик**, в Gemini API есть бесплатный уровень. Ручного управления ударением нет, только капитализация и `<short pause>`.
- **ElevenLabs стоит своих денег по цене, но не по доступу.** Условия использования прямо запрещают пользователям, находящимся в России. Аккаунт можно потерять вместе с голосом. Брать только по решению владельца и без привязки всего конвейера к нему.
- **Китайские сервисы:** Qwen3-TTS-Flash дешевле всех ($0,14), но по отзывам путает русские ударения. MiniMax стоит $0,84–1,40. Fish Audio сейчас бесплатен до 30.11.2026, но для разработчиков без гарантий, а запросы могут идти на обучение. BytePlus/Volcengine русского не заявляет.
- **Локально на CPU нового кандидата лучше TeraTTS нет.** Сильные русские открытые модели либо некоммерческие (Silero v5.x, XTTS-v2, F5-ru), либо рассчитаны на GPU (CosyVoice 3, Chatterbox, Qwen3-TTS, Fish S2).

## 2. Сколько текста в 20 минутах

Измерено на реальной лекции University `semester-3/Neural-Networks/video/lecture-01`, это `part1–3.py`, ролик `lecture01.mp4` длиной 1412,8 с (V-20). Посчитаны все строки `say`:
156 фраз, **16 524 знака** (UTF-8 — 30 075 байт), 2 520 слов, самая длинная фраза — 210 знаков.

Пересчёт на 20 минут ролика, ×1200/1412,8: **≈14 035 знаков, ≈25 545 байт UTF-8, ≈2 140 слов, ≈133 фразы.**
Для тарифов с оплатой по длительности звука беру верхнюю оценку: **≤1 200 с речи**, то есть ≤30 000 аудиотокенов при 25 ток/с. Чистая речь короче ролика, потому что в нём есть удержания кадра.
Курс ЦБ на 16.10.2026: **83,76 ₽/$**.

**Стоит ли платный вариант денег рядом с бесплатной Tera?** По деньгам — да, это меньше $1,5 за 20-минутную лекцию у любого поставщика, а у Yandex и Gemini около $0,25. Но доказательства, что он **лучше звучит на наших текстах**, у нас нет: ни один облачный голос мы не слушали. Обе прежние попытки (V-694, V-18) остановились на этом же месте. Переходить на «бумажное» качество было бы ошибкой. Порядок такой:

1. **Слепой тест.** 10 фраз из `lecture-01`: числа словами, термины («сигмоида», «кросс-энтропия»), омографы, фраза с `+`. Варианты: Tera `ru_m1`, Yandex (2 голоса), Gemini 3.8 Flash (бесплатно), по желанию ElevenLabs v3. Всего около 1 500 знаков, меньше $0,50 на всё. Слушает владелец, не видя названий. Deepgram recall проверяем по каждой фразе тем же `check`.
2. Если облачный голос выиграет: добавить в `scripts/video_artifact` движок с кешем по ключу текста и голоса, как у Tera. Tera остаётся без сети и запасным. Это отдельная задача на реализацию.

Для пункта 1 нужно слово владельца: платный API — новый класс расходов, плюс аккаунты Yandex Cloud и Google AI Studio.

## Ограничения

- Звук не слушался. Вся колонка «качество» — со слов вендоров или из отзывов, кроме выбора Tera и Vosk самим владельцем.
- По V-18, без перепроверки сегодня: Azure $16/M, характеристики SaluteSpeech, MOS MiniMax, русские голоса Google, отзыв о Qwen3, страны OpenAI и дата отключения gpt-4o-mini-tts.
- Не проверены: русский у Inworld (список языков за логином), лимиты бесплатного уровня Gemini, тексты коммерческих оферт Yandex, MiniMax и Cartesia, реальная оплата российской картой в каждом сервисе.
- Не запускал ни одну новую локальную модель. Те, что достаточно лёгкие для CPU, уступают Tera по лицензии или функциям, а остальные требуют GPU. Скорость Chatterbox, CosyVoice и Qwen3 на нашем CPU не мерил.
- Длительность речи взята по верхней оценке, 1 200 с на 20 минут ролика. Для тарифов по аудиотокенам реальная цена ниже.
