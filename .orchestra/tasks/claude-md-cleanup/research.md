# Чистка CLAUDE.md по смыслу (не по байтам)

## Вопрос

Что было вырезано из `CLAUDE.md` 2-3 августа под несуществующий лимит 32 KiB, что из этого
стоит вернуть, и что честно подлежит удалению по смыслу. Baseline: 32 821 байт, 211 строк.
Критерий отбора (задан оркестратором): **помогло бы агенту на СОВСЕМ ДРУГОЙ задаче через месяц?**

## Установленный факт: лимита не было

`~/.codex/config.toml` локально `project_doc_max_bytes = 98304`, на VPS `65536`. Строка в
`CLAUDE.md` про «32 KiB» описывала ДЕФОЛТ Codex, а не действующую конфигурацию, и протухла
с момента, когда страховку выставили. Исправлено в `780d45a`.
Уровень доказательства: **CONFIRMED** — прочитан конфиг, не память.

Ущерб измерим: 6 коммитов с заголовком «сжать под лимит» (`5cba732`, `2f9707d`, `79990ba`,
`b53b89d`, `3b53eec`, `a54ff2a`). Три из них (`b53b89d` → `3b53eec` → `a54ff2a`) правят ОДНУ
И ТУ ЖЕ строку про деплой, каждый раз откусывая несколько байт:
`| wc -l` → убрано, `со снимком владельцев и сверкой %a` → `со снимком владельцев` → `со снимком прав`.
Это чистая потеря операционной детали ради байтов, которых никто не считал.

## Что возвращено (3 правила)

## Что удалено (9 правил) — обоснование построчно

Все проверены грепом по коду: механизм либо закрыт в коде, либо это разовый факт.
Полные формулировки перенесены в `docs/archive/sessions/2026-08.md`, не потеряны.

1. **$2230 на одного агента / research-фан-аут** — факт о расходе за конкретную неделю, не
   инструкция. Решение о фан-ауте принимается по текущей квоте, а не по прошлогодней цифре.
2. **«Opus 5 заменяет Sol» — перепутали легенду графика** — частный случай уже имеющегося
   «проверяй формулировку в первоисточнике». Дубль по смыслу.
3. **Рубли вместо `$` в стоимости модели** — одноразовый фикс фронта, `MODEL_COST_CURRENCY`
   в коде. Агенту другого проекта бесполезно.
4. **`ctx=100%` и лишние компакты** — закрыто типами в `app/usage_contract.py` (проверено:
   файл существует, типы на месте). Симптом не воспроизводим.
5. **Opus печатает tool-call текстом** — закрыто детектором `app/tool_call_guard.py`
   (проверено: файл существует). Поведенческая часть сохранена строкой «проверять артефакт,
   а не рассказ» — она и есть переносимое правило.
6. **Красная точка «непрочитано»** — закрыто кодом, узкий баг дашборда.
7. **Переиспользование номеров задач** — починено в `_next_par` (проверено: `app/tm.py:63`).
8. **TG flood control 429 / таймаут `send_file`** — закрыто константой в коде.
9. **Хроника падения Codex 30.07 на 4 абзаца** — сжато до одной строки «пустое падение →
   первым делом `/api/usage`». Инструкция сохранена, хроника ушла в архив.

## Дубли, слитые в один пункт (6 → 3)

- **ONNX/93°C** + **`nice` не спасает от вытеснения по памяти** — это ОДИН инцидент, описанный
  дважды, с расходящимися рецептами (`nice -n 15` против `systemd-run MemoryMax`). Слито в один
  пункт с обоими механизмами; `MemAvailable`-гейт выделен отдельной строкой как самостоятельная проверка.
- **«Новый рантайм расширяет контракт»** + **«сузил валидацию на shared runtime»** — оба говорят
  «проверяй по живой БД, не по фикстурам». Слито, цифра 27/330 сохранена как доказательство.
- **«Копия расходится с оригиналом»** поднято в заголовок группы «Дубли и рассинхрон» — оно
  обобщает три частных случая, которые под ним и лежат.
