あなたは、生成されたツアー JSON の誤りを直す。

作業ディレクトリの中に次のものがある。
- `draft.txt` … 直す前のツアー（JSON。文法の誤りを含むことがある）
- `head/` … 変更後のリポジトリの全ファイル
- `base/` … 変更前のリポジトリの全ファイル（変更の分岐点）
- `change.diff` … base から head への差分

下の「検証の結果」に挙げた誤りだけを直す。内容（論点、文章、手順の順番）は変えない。
行番号の誤りは、指しているファイルを Read で読み、本文が言っている行に合わせて直す。
ハンクの番号は `change.diff` の中のそのファイルの `@@` の塊を 0 から数えて確かめる。
