Экономика: токен дорогой, работа может быть дешевле

Credits — официальный текущий rate card. Доллары ниже — API-equivalent, не фактическая оплата подписки.

per-token

Astra → Sol

2.5× input, cache и output credits. Никакой магии: если токенов столько же, Astra проиграла.

per-task coding

Astra → Sol

AA измерила около трёхкратного сокращения токенов. На max задача `$4.72` против Sol max `$5.00`.

general work

Astra → Sol

Только ≈10% меньше output tokens; max-task на 75% дороже при том же округлённом Intelligence 61.

Две ловушки

  • Fast: 2.5× credits ради скорости до 2× — default выключен.
  • >272K input: API применяет 2× input/cache и 1.5× output ко всему запросу; перенос на included allowance не опубликован.
  • 1.05M: это API window, не доказанный ChatGPT-auth budget Orchestra.

Effort: medium — default, xhigh — длинная работа

`xhigh → max`: тот же округлённый coding score, примерно +44% цены и +40% токенов. На общем Intelligence Index: 61 → 61 при +39% цены.

Одно значение на старте: `medium`. Оно уже выглядит сильнее Sol xhigh на coding harness, но не сжигает верхний budget без своей канарейки.
Role-aware после канарейки: worker `medium`; orchestrator `high`; full-cycle `xhigh`; max только вручную.

Где Astra заменяет Sol — и где нет

сильный кандидат
  • Agentic coding: Terminal-Bench 4.0 57.9 vs 37.3; migration 63.9 vs 42.7.
  • Computer use: OSWorld 72.6 vs 65.7, около 40 против 75 минут.
  • SRE/security: SRE-Bench 88.0 vs 55.9; свежий ExploitBench 39.0 vs 11.5.
  • Long-horizon: AA-Briefcase примерно +80 Elo; экспериментальные notes/search across windows.
  • Надёжность знания: hallucination rate 92% → 51%, accuracy при этом выросла.
не blanket replacement
  • General intelligence: 61.2 vs 60.9, но Astra max-task +75%.
  • Long-context reasoning: AA-LCR регресс 2–3 пункта.
  • SciCode / banking: регресс 2–3 пункта.
  • Presentation: качество подачи снизилось, Sol остаётся лидером AA.
  • Luna tasks: экономически бессмысленно; Opus tasks: теряется отдельный пул и независимость runtime.

Впихнуть без костылей

Сейчас Astra отсутствует в entitlement, поэтому это точная последовательность после появления в catalog, а не правка production сегодня.

  1. `ModelSpec` + alias `astra`; существующий runtime `codex`.
  2. Price/context maps по живому ChatGPT-auth измерению; отдельная обработка >272K для виртуальной цены.
  3. Общий quota bucket `codex`; новый пул не выдумывать.
  4. Role-specific efforts: medium / high / xhigh; reducer остаётся Luna.
  5. Три A/B: coding, research, full-cycle. Frozen commit/prompt/oracle; A/B/A/B; fresh thread.
  6. Context management тестировать отдельно, иначе модель и память смешаются в один неразличимый эффект.
  7. Sol держать rollback до фактической победы Astra на credits/task и acceptance.
