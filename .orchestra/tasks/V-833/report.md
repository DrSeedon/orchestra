# V-833 — защита миграции каталога V-621

## Изменение

`migrate_v621()` теперь сравнивает переданный домашний файл с `.orchestra/projects.yaml` основного checkout, найденного через Git common dir кода миграции. Если приложение запущено из linked worktree, временной копии или каталога без определяемого основного checkout, функция возвращает `state=skipped` до чтения и любой записи: без backup, правки и git commit.

До разбиения записей миграция проверяет каждый scope, отличный от домашнего, и уже существующие `include_scopes`. Если собственный файл такого scope разрешается в тот же файл каталога или его Git common dir совпадает с домашним репозиторием, миграция возвращает `state=skipped`, не меняя каталог. Это защищает также от вложенного scope и другого пути к тому же репозиторию.

Парсер `include_scopes` сравнивает разрешённый путь включаемого `projects.yaml` с файлом-источником. Включение самого себя теперь выдаёт `CatalogError` с указанием, что каталог не может включать собственный файл, до агрегации тегов.
