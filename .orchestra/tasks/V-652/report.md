# V-652 — временная шкала квот пула

## Реализация

В `QuotaPanel` добавлен график такой же высоты, расположенный над прежним. Его диапазон — 168 часов; центр соответствует `generated_at` ответа карты квот. Тики и подписи форматируются через i18n-язык панели и `Asia/Krasnoyarsk`. Интервалы 00:00–08:00 Красноярска подсвечены фоном. На центральной вертикали показаны текущие значения известных полос. Прогнозных точек после центра нет.

`/api/usage/quota-map` добавляет `timeline.points` отдельно от прежнего `trace.points`: снимки `usage_snapshots` за последние 84 часа с фактическими `ts`, процентом решающего окна, длительностью и временем его сброса. Прежний `trace` и построитель старого SVG не менялись. Прореживание временного ряда сохраняет обе точки по сторонам каждого снижения utilization, чтобы не потерять фактический сброс.

Повторяемые диагональные пороги строятся для каждого цикла длительностью `window_minutes` от `resets_at`: предыдущие фактические границы берутся из снимков, текущая — из окна API, будущие продолжены по длительности текущего окна. Если исторические границы не дошли, предыдущие интервалы выводятся из текущей длительности и сброса. У полосы остаётся её собственный hard stop. ## Ограничение данных

Скриншот и браузерная проверка используют фикстуры, а не текущую боевую БД. Источник API — существующие снимки `usage_snapshots`; код не синтезирует точки при отсутствии снимков. Поэтому полнота реальной истории по каждому пулу не проверена: если сборщик не сохранял `provider_usage` за часть 84-часового диапазона, на соответствующем участке истории не будет. В этом worktree невозможно подтвердить фактический пробел для конкретной полосы.

Старый SVG-код оставлен без изменений. Python-правка требует рестарта Orchestra для попадания в живой процесс; рестарт не выполнялся.
