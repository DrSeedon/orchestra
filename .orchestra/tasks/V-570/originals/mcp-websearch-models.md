# 🔍 MCP: Web Search & Image Generation — модели и цены

Справочник по моделям поиска и генерации картинок. Обновляется при смене цен/появлении новых моделей.

## Web Search — 3 уровня (СТРОГО)

### 1. Основной поиск — `mcp__websearch__search` (дефолт)
- Модель: `sonar-pro-search` (дефолт, параметр можно не указывать)
- Агентный мульти-шаг поиск, лучшее качество
- ~$0.02/запрос, ~$13/мес при активном юзе
- **Когда**: сравнение, анализ, юридика, всё что не укладывается в 1 предложение ответа

### 2. Быстрый поиск — `mcp__websearch__search` (model: `sonar`)
- Дешёвый однопроходный поиск
- **Когда** (и ТОЛЬКО когда): курс валют, синтаксис языка, "что такое X", формат даты, версия пакета
- Правило: если ответ помещается в одно предложение — `sonar`. Иначе — дефолт.

### 3. Перепроверка — встроенный `WebSearch` (не MCP)
- Встроенный в Claude Code поиск, #1 в Search Arena
- $0 (включено в подписку)
- **Когда**: верификация фактов, нужны URL источников, не жалко лишнего шага

### ❌ НИКОГДА не юзать
- `sonar-pro` — стоит как pro-search, качество на уровне `sonar`
- `sonar-reasoning-pro` — то же самое

Проверено бенчмарками 14.03.2026.

### Язык запросов
- **Английский** — лучше результаты в 90% случаев
- **Русский** — только если тема РФ-специфичная (налоги, законы, локальные сервисы)

## Image Generation — `mcp__websearch__generate_image`

Генерация через OpenRouter. Можно передавать любой OpenRouter model ID напрямую.

| Модель | Цена | Когда юзать |
|--------|------|-------------|
| **`nano-banana`** (дефолт) | $0.50/M input + $3/M output | SOTA edit/gen, Gemini 3.1 Flash Image |
| `riverflow-fast` | $0.02/img | Бюджет, приемлемое качество |
| `seedream` | $0.04/img | Альтернатива riverflow |
| `gemini-flash-image` | $0.04-0.07/img | Средний сегмент |
| `sourceful/riverflow-v2-fast` | $0.02/img | Прямой OpenRouter ID |

### ❌ НИКОГДА
- `gpt-5-image-mini` — дорого, качество не оправдывает

### Правила
- **Промпты на английском** (лучше результаты)
- **По одной картинке за раз**, НЕ параллельно — сначала показываем юзеру результат, потом решаем нужна ли ещё
- **Показывать сразу через Read** после генерации
- **Если сохранение зафейлилось** — файл всё равно в кеше `~/.claude/mcp-servers/websearch/generated/`, копировать оттуда в нужное место без переспрашивания
