## VPS и привилегии

Привилегированные действия на этом VPS разрешены владельцем. В процессе Orchestra
прямой sudo ограничен NoNewPrivileges; штатный доступ — `ssh kesha@localhost`.
Разрешение привилегий не отменяет правил проекта и границ текущей задачи.

На VPS не поднимать личные Hiddify/1234x-туннели ноутбука. Прямые HTTPS-запросы к API
достигают ответа; доступность конкретной API-функции этим не доказана. Управление
личными прокси остаётся ручным: автоматические failover и балансировка по IP запрещены.
Параметры личных прокси задаются HTTP_PROXY/HTTPS_PROXY окружения.
Захорон — старый клиент: доступ сохраняется, его инфраструктуру не трогать.
