# Личные правила работы с результатами инструментов

## Изображения

- Промпты на английском.
- По одной картинке, не параллельно: показать → решить, нужна ли ещё.
  Не генерировать заново то, что уже есть.
- Сгенерированное сразу показать. Если сохранение не удалось, исходный файл искать
  в ~/.claude/mcp-servers/websearch/generated/ и копировать без переспрашивания.

## Документы и навигация

- mcp__mcp-pandoc__convert-contents — MD→DOCX, сохранять рядом с исходником.
- mcp__serena__* — LSP для ссылок на символы (find_referencing_symbols), структуры
  классов (get_symbols_overview) и рефакторинга; для строковых литералов, TODO, URL
  и .sh/.yml/.md/.json — текстовый поиск.
- mcp__github-actions__* — CI; mcp__github__* — issues/PR.
- Per-project MCP задаются в .mcp.json проекта; личные конфиги — ~/.claude/mcp-configs/.
