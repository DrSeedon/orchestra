# Применение глобальных файлов: только после одобрения пакета

Одобрено решение об одном личном источнике. Само внешнее применение ещё НЕ одобрено
и здесь не выполняется. Воркер редактирует только свою worktree; внешнее применение
выполняет полномочный оркестратор после решения владельца.

Канон: /home/kesha/.claude/CLAUDE.md. /home/kesha/.codex/AGENTS.md станет symlink
на ../.claude/CLAUDE.md. В proposed/ лежит аналогичная рабочая ссылка global-codex.md
на global-claude.md; оба читателя видят одни байты. Третьего активного текстового
источника не создаётся. Личный MCP-справочник остаётся по прежнему отдельному адресу;
в глобальном файле только указатель.

Применение одним согласованным пакетом:

1. Закрыть вопросы из questions.md или явно одобрить сохранённые пометки неопределённости.
2. Проверить текущие SHA256 трёх внешних исходников против sources.json. Если хоть один
   изменился, остановиться и пересобрать diff, не перетирать чужие свежие правки.
3. Перед заменой сделать рядом с КАЖДЫМ внешним исходником отдельную копию с уникальным
   суффиксом V-570 и временем; сохранить владельца/режим и исходный тип файла.
   Записать точные backup-пути в этот отчёт. Не перезаписывать существующие backups.
4. Подготовить новые обычные файлы рядом с целевыми, сохранить их владельца/режим,
   проверить равенство предложенным байтам. Заменить MCP-справочник и канонический
   CLAUDE.md атомарным rename, затем заменить Codex-файл ссылкой атомарным rename.
   Это не атомарная транзакция трёх путей: при частичной ошибке восстановить весь пакет
   из сохранённых исходников до продолжения. Не использовать rm-rf для уборки.
5. Проверить readlink/resolve Codex, равенство содержимого, hash канона/справочника,
   наличие backups. Проверить diff корней и принять модульный пакет через обычный
   merge gate. Новые модули не считаются заменой глобальных файлов, пока внешняя
   часть ещё не выполнена; до этого временно остаётся исходное дублирование у Claude.
6. Не перезапускать Orchestra. Модули/глобалы имеют свои моменты перечитывания;
   не выдавать файловое равенство за проверенную доставку во все уже живые сессии.

Откат внешней части: вернуть три исходника с их владельцами/режимами и исходным типом
из записанных рядом backups. Старый Codex-файл был обычным файлом, не ссылкой:
его восстановление должно вернуть именно этот тип. Исходники внутри задачи —
доказательство и запасная копия, но не замена обязательных backups рядом с файлами.
Репозиторную часть откатывать отдельным обычным revert принятого коммита; git не
откатывает внешние файлы. После любой частичной операции проверить все три пути.
