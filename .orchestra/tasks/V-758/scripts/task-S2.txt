Собери таблицу по тестам репозитория. Для каждого файла tests/test_*_5NN.py (имя оканчивается на три цифры, первая из них 5, то есть _500…_599) запиши строку в файл inventory.csv в корне репозитория. Колонки строго: file,lines,tests — file: путь вида tests/имя.py; lines: число строк файла (как считает `wc -l`); tests: число определений, у которых строка после отступа начинается с `def test_` или `async def test_` (включая методы классов). Заголовок file,lines,tests, строки отсортированы по file. Ничего другого в репозитории не меняй, не коммить.
