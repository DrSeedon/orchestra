# #151 — план: нативные скиллы Codex

## Подход одной фразой

Дать `inject_skills_to_worktree` второй целевой путь (`.codex/skills/<name>/SKILL.md` для
codex-рантайма), снять с `_refresh_skills` гейт `backend_type != "claude"`, а наше оглавление
убрать за флаг с дефолтом «выключено». Один механизм доставки, два адреса — не две копии кода.

## Решение оркестратора, по которому строю

Детекта доступности нативного пути НЕТ ни по версии, ни фактом. Инъекция всегда; оглавление
`build_codex_skills_index` живёт как ручной fallback под флагом. Согласен и аргументов против
не имею: детект по версии — парсинг чужой строки (сегодня уже обожглись на `--help`), детект
фактом — процесс на каждый коннект ради ответа, меняющегося раз в полгода.

## T0 — БЛОКЕР: `.codex/` в исключениях (делать первым)

Замер, подтверждающий блокер (все три цели):
```
seedon  gitignore:0  exclude:0
polus   gitignore:1  exclude:0
games   gitignore:0  exclude:0
```
Только `polus` игнорирует `.codex` своим `.gitignore`. Без правки инъекция даёт untracked-мусор
в `seedon` и `games` — ровно рецидив #149.

- **Files:** `app/workspace.py`
- **Что:** `.codex/` в `_WORKTREE_EXCLUDES`; вызов из `prompting.py` получает
  `only=(".claude/", ".codex/")`.
- **AC:**
  - в репозитории без `.codex` в ignore после codex-инъекции `git status --short` не содержит `.codex`;
  - `AGENTS.md`/`codex_sessions.json`/`*.round` по-прежнему НЕ дописываются при инъекции
    (ограничение `only=` из #149 не ослаблено);
  - ничего не записано → `info/exclude` не тронут.
- **blocked-by:** none

## T1 — второй адрес доставки в `inject_skills_to_worktree`

- **Files:** `app/prompting.py`
- **Что:** параметр целевого подкаталога (`.claude` | `.codex`). Вся остальная механика —
  `tracked_paths`-гейт, запись только при расхождении байт, tmp+mv, счётчик, вызов
  exclude — переиспользуется как есть. **Вторую копию механизма не пишу** (моя же запись в
  памяти после #149).
- **Почему параметр, а не второй вызов с другим путём:** имя каталога — единственное отличие;
  выносить его в аргумент дешевле, чем дублировать 40 строк с двумя местами для расхождения.
- **AC:**
  - claude-путь кладёт в `.claude/skills/<name>/SKILL.md` (регресс #149 не сломан);
  - codex-путь кладёт в `.codex/skills/<name>/SKILL.md`;
  - трекнутый `SKILL.md` не перезаписывается в ОБОИХ вариантах;
  - совпадающий файл не переписывается (steady state = 0 записей).
- **blocked-by:** T0

## T2 — снять гейт рантайма в `_refresh_skills`

- **Files:** `app/session.py`
- **Что:** сейчас `if self.backend_type != "claude": return`. Заменяется на выбор адреса по
  рантайму: claude → `.claude`, codex → `.codex`. Прочая логика (`worktree_path or cwd`,
  `skills == "all"`, глушение исключений) не трогается.
- **Ограничение:** правка точечная, `_ensure_backend` не трогаю вовсе.
- **AC:**
  - Codex-агент с worktree получает `.codex/skills/`;
  - Codex-оркестратор без worktree получает их в `cwd`;
  - Claude-агенты продолжают получать `.claude/skills/` (регресс #149);
  - исключение внутри обновления не ломает `connect()`.
- **blocked-by:** T1

## T3 — оглавление за флаг

- **Files:** `app/runtime_registry.py`
- **Что:** `_codex_factory` дописывает `build_codex_skills_index` только при
  `ORCHESTRA_CODEX_SKILL_INDEX=true`. Дефолт — выключено. Функция и её тесты остаются.
- **Конвенция берётся существующая** (`app/rag_service.py:19`):
  `os.environ.get("ORCHESTRA_CODEX_SKILL_INDEX", "false").lower() == "true"` — не изобретаю
  свой формат флага.
- **Почему не удалить:** проектный каталог не документирован в `--help` и проверен ровно на
  `0.145.0`; флаг — наше явное решение вместо угаданного состояния чужого CLI.
- **AC:**
  - по умолчанию `system_prompt` Codex НЕ содержит `## Available skills`;
  - при `=true` содержит (fallback жив);
  - оба источника одновременно не активны → дубля имён (F6) не возникает.
- **blocked-by:** none

## Что НЕ делаю

- Не удаляю `build_codex_skills_index` и его тесты.
- Не переписываю frontmatter скиллов: F8 — `roles:`/`integrations:` не мешают discovery.
- Не перевожу скиллы в папочный формат со `scripts/`: F7 — сегодня все плоские, выгоды нет.
  **В отчёте папочной доставкой работу не оправдываю** (прямое указание оркестратора).
- Не трогаю `.claude/`-копии в воркти Codex-агентов: они невидимы Codex, но их удаление —
  деструктив в чужих деревьях, отдельная задача (как и 31 orphan из #149).

## Adversarial self-review — 3 слабых места

1. **Codex-агенты получат скиллы ДВАЖДЫ на диск, если у них есть и `.claude/`-копии из #149.**
   Дубля в промпте не будет (Codex не видит `.claude/`), но на диске мусор. Осознанно не чищу
   (см. выше), в отчёт — как известное ограничение.
2. **Флаг по умолчанию выключен = молчаливая потеря оглавления на машине со старым CLI.**
   Митигация: это ровно решение оркестратора, и оно обратимо одной переменной. Но fail loud
   тут нет — агент просто не увидит скиллов. Записываю в отчёт как компромисс, а не прячу.
3. **`prompt-input` не докажет, что модель ПРИМЕНИЛА скилл.** Граница принята оркестратором
   явно; в отчёте пишу «видит — доказано, применяет — отложено до 8 августа», без размывания.
