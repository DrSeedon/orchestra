# План запуска экспорта, beta

На первый месяц ожидаем 240 активных клиентов, по 3 экспорта в день у каждого.
Обещаем обслуживать этот суточный объём без переноса на следующий день (capacity).
Месячный бюджет инфраструктуры при этой нагрузке — не больше 800 EUR (budget).
После неудачного релиза обещаем восстановить экспорт за 10 минут (rollback).

Основания готовности приведены в [проверках экспорта](export-checks.md).
По остальным продуктам в каталоге есть отдельные заметки; их релизы не входят в этот запуск.
