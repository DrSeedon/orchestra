# Значок мобильного приложения

Дизайнер предложил три варианта: круг, квадрат со скруглёнными углами и монограмму.
В этом месяце команда сравнивает читаемость на маленьких экранах. Цвета сохраняются
из существующей палитры. Экспорт отчётов, серверная нагрузка и восстановление данных
не входят в эту визуальную работу. Финальный вариант ещё не выбран.
