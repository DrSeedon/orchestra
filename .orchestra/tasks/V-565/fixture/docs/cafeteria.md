# Столовая: меню и закупки

Этот документ относится к питанию сотрудников в офисе. Поставщик доставляет обеды
по вторникам и четвергам. Закупки согласует администратор офиса. Для вегетарианского
меню предусмотрены отдельные контейнеры; возвратная тара хранится у входа.
Список аллергенов лежит у поставщика. Оплата выполняется по фактически полученным
порциям. Кухонное оборудование проверяет арендодатель. Это не инфраструктура экспорта.
