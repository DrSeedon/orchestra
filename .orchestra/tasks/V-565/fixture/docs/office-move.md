# Переезд офиса

Инвентаризация мебели завершена. Столы промаркированы по отделам, мониторы перевозятся
в индивидуальной упаковке. Расписание доступа в грузовой лифт согласовано с охраной.
Локальная сеть офиса будет проверена после монтажа. Продуктовые серверы и beta-клиенты
размещены отдельно; переезд не меняет их конфигурацию и не влияет на план экспорта.
