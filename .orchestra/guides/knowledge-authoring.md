# Запись и актуализация знаний

Канонические правила проекта — AGENTS.md; база знаний хранит выводы и доказательства,
не вторую копию всех правил. Одна тема имеет одного владельца; README — только указатель.

## Разделы Markdown

- Established: принятые выводы. Для изменяемого состояния обязателен источник-владелец
  и дата наблюдения; не переносить старый снимок в настоящее время без проверки.
- Rejected: опровергнутые гипотезы и отказанные решения с причиной. Сохранять, чтобы
  следующий агент не повторял проверенный тупик.
- Historical observations: замеры и сообщения о состоянии на указанную дату.
  Они остаются доказательствами прошлого, но не являются текущим конфигом.
- Gaps: вопросы, на которые источники не дают подтверждённого ответа.
- Источники: точные ссылки на исходные артефакты и код.

Раздел Markdown — навигация, не новая схема статусов. При работе через typed knowledge
API использовать существующие status/resolution и validation в app/ia/knowledge.py:
замена принятого факта требует supersede, противоречие — disputed, одинаковый факт — no-op.
Не придумывать параллельные enum или считать срок перепроверки доказательством ложности.

## Изменение факта

1. Указать предмет и область: решение владельца, свойство кода либо датированный замер.
2. Приложить проверяемое доказательство и дату. Намерение не записывать как исполнение.
3. При отмене явно пометить старый вывод RETRACTED/superseded и связать с новым основанием.
   Не стирать причину отказа. Исторический документ можно сохранить без переписывания,
   но ссылаться на него как на исторический, а не как на действующий регламент.
4. Не выводить текущие версии, квоты, цены, маршруты, процессы и деплой из старых чисел.
   Прочитать актуального владельца либо явно оставить ответ неизвестным.
5. Не удалять сырьё по одному LLM-конспекту: полнота и корректность извлечения требуют
   отдельной проверки. Вывод без источника — кандидат, не принятый факт.
6. Новая тема получает ссылку в README. При переносе проверить входящие ссылки.

Проверять качество вопросами пользователя: найден ли нужный вывод, отличена ли отмена,
сохранена ли неизвестность. Число файлов, валидный JSON и исправные ссылки не заменяют это.
