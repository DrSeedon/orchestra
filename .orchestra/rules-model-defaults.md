Применять после проверки и фактической активации модели в живом каталоге Orchestra. Не прерывать рабочие ходы ради переключения. Новое разрешение на рестарт, удаление, платный API или обход квот из этого решения не следует. Обычные исполнители по-прежнему идут через хаб; отдельное исключение защищённой локальной Luna принадлежит model-routing. Существующие очереди, роли и история сохраняются.

Смена живых сессий и модель по умолчанию в pipeline проверяются отдельно от добавления строки каталога. Нельзя включать в горячо читаемый pipeline новый model ID, пока живой Python registry его не знает. Само наличие модели в Codex model/list не доказывает активацию каталога Orchestra или успешный inference.
