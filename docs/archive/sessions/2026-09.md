### Решения юзера, принятые за сессию

  не используются. Условие: миграция обязана быть самовосстанавливающейся, чтобы агент, пришедший
  в наполовину переехавший проект, увидел внятный отказ с инструкцией, а не пустоту.
- **Задачи живут файлами в репозитории проекта**, одно дерево, без грязи: пишет их только
  Orchestra и только в главном чекауте, ветки воркеров их не содержат, коммит делается до мержа.
  Отдельный git для задач (нынешний `canonical` со своим репозиторием) — убрать.
- **Номера задач получают букву происхождения** (`#429` на ноуте, `#V429` на сервере). Номер,
  названный один раз, не меняется никогда; схемы с перенумерацией при синхронизации отвергнуты.
- **Раскладка базы знаний — A, тематические файлы**, при трёх условиях: перенос факта между темами
  разрешён, один ключ в двух файлах запрещён глобально, ключ и тема живут на строке. Ключ —
  человекочитаемый и неизменяемый; вычисляемый из содержимого отвергнут (переформулировка
  превращала бы правку в новый факт).
- **Ресёрчи — авто-апрув всегда**, апрув нужен только на реализацию. **Рестарт — мой, без спроса,
  но пачкой**, а не на каждый чих. **Codex жжём по существующей линии допуска**, резерв 5% отменён.
- **Вложения в сообщениях** (#431, смержено): текст хранится как есть, потолок 64 КБ, без
  подстановок и слепков — «память дешёвая, не надо лишней хуйни».
- **Docker удалён**, портфолио уехало в COG-second-brain, `docs/portfolio` удалена локально.
- **Вся документация в репозитории пишется для агентов** — он не читает `.md` вовсе. В `docs/`
  остаётся только то, что читает ПОСТОРОННИЙ: картинки README, инструкции оператора.
