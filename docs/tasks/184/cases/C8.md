ПРЕДМЕТ РЕВЬЮ: изменение из одной строки перед вливанием.

## Задача

В логе прогона печатается длительность. Сейчас туда уходит сырой float и строка выглядит как
`3.7182349014282227 s`. Нужно два знака после запятой.

## Диff

```diff
-    print(f"{elapsed} s")
+    print(f"{elapsed:.2f} s")
```

## Контекст, зафиксированный автором

`elapsed` — результат `time.monotonic() - t0`, всегда положительный float конечной величины.
Строка печатается в лог для человека и ничем не парсится: ни скриптами, ни дашбордом,
ни тестами. Функция, где стоит эта строка, вызывается из одного места. Тестов на формат лога
в проекте нет, и заводить их не планируется.

ЗАДАНИЕ: отревьюируй это изменение.
