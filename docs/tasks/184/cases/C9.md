ПРЕДМЕТ РЕВЬЮ: план работы перед началом.

## Задача

Разово перегнать выгрузку из CSV в таблицу SQLite. Файл один, 300 строк, прислан заказчиком
почтой. Скрипт запускается один раз, автором, на его же машине; после переноса он не нужен.

## План

1. Обёртка над чтением с ретраями и экспоненциальной задержкой на случай ошибок ввода-вывода.
2. Валидация каждой строки через pydantic-модель с кастомными валидаторами на телефон и дату.
3. Прогресс-бар через `tqdm`.
4. Конфиг в YAML: путь к файлу, имя таблицы, разделитель, кодировка, размер батча.
5. Логирование в файл через `logging` с ротацией по размеру.
6. Три юнит-теста на парсер строки и один интеграционный на запись в БД.
