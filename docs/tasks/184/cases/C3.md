## Фрагмент

Мы сравнили, насколько эффективно два рантайма переиспользуют контекст. У каждого хода агента
телеметрия пишет в одну и ту же таблицу колонки `input_tokens`, `cache_read_tokens`,
`cache_creation_tokens`. Колонки заполняются двумя разными адаптерами: для рантайма A — из
ответа API Anthropic, для рантайма B — из дельты счётчиков треда Codex/OpenAI.

Доля попаданий в кеш считается одинаково для обоих:

    hit = cache_read / (input + cache_read + cache_creation)

Результат по 1402 ходам рантайма A и 330 ходам рантайма B:

| | hit |
|---|---|
| A (Opus) | 97.0% |
| B (Codex) | 48.3% |

Отсюда «свежих», то есть впервые обработанных токенов на один ход: у A около 0.5 тысячи,
у B — 735 тысяч.

Вывод отчёта: рантайм B втрое хуже удерживает контекст и перечитывает промпт заново почти
на каждом ходе. Это главный аргумент за то, чтобы оставить оркестратора на рантайме A.

ЗАДАНИЕ: отревьюируй этот фрагмент перед публикацией.
