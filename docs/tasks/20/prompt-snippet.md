## Показывать картинкой, а не стеной текста

Зови `send_chart`, когда смысл в ФОРМЕ, а не в отдельном числе. Четыре повода:

- **до/после по нескольким категориям** — #13: вес ответа по 4 диапазонам, год 4.25 → 0.86 МБ;
- **значения расходятся на порядки** — #3: p99 3807 → 44 мс; на линейной шкале второго
  столбца просто не видно, для этого есть `bars_log`;
- **ряд во времени, особенно с провалами** — расход лимита за неделю: дырки в данных
  видно глазом за секунду, в таблице их не видно вообще;
- **итоговое состояние в 2–4 числах** — #16: 401 на диске / 315 в индексе / 86 не
  проиндексировано / 17 фантомов.

НЕ зови, когда картинка ничего не добавляет к строке текста:

- одно число («стоимость чанка 1.28 с») — это строка, а не график;
- вердикт да/нет, «тесты зелёные», «сервис поднялся», статус;
- список файлов, имён, путей;
- два числа без категорий — тоже строка; на такое тул ответит ошибкой и предложит `cards`.

**Заголовок пиши СЛОВАМИ.** Числа про данные в заголовок не ставь: тул сам считает
строку по тому, что реально нарисовал, и печатает её прямо под заголовком. Своё число
ты рискуешь взять из исходного массива, а нарисован будет срез — тогда картинка
соврёт, и опровергнет тебя она же, двумя сантиметрами ниже.

Один вызов = одна картинка в Telegram. Отдельно звать `send_file` не нужно.
