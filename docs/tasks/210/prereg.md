# #210 — предрегистрация ретроспективного реплея (написано ДО прогонов)

Коммит этого файла обязан предшествовать спавну воркеров. Критерии ниже после старта не меняются.

## Что меряю

Гипотеза H1: тикет из уже готового плана можно отдать дешёвому исполнителю (Luna,
`gpt-5.6-luna`), и он выдаст по существу ту же работу, что реально уехала в `main`, за долю
цены — так, что экономия переживает цену передачи контекста (холодный старт нового воркера +
чтение тикета).

Гипотеза H0 (конкурирующая): тикет плана содержит не только исполнение, но и решения; дешёвый
исполнитель выдаст правдоподобный, но неверный код, и переделка съест экономию.

**Фальсификатор H1:** ground-truth тесты из `main`, которых воркер не видел, краснеют на его
реализации по существу (не по имени символа).
**Фальсификатор H0:** те же тесты зелёные, а цена ниже baseline на порядок.

## Критерии, зафиксированные до прогона

Оракул: файл ground-truth тестов копируется в дерево воркера ПОСЛЕ его DONE и запускается
`uv run python -m pytest <файл> -q`.

- **PASS** — ≥ 90% тестов ground-truth зелёные, и КАЖДЫЙ красный классифицирован как расхождение
  в имени/сигнатуре, которого нет в тексте тикета.
- **PARTIAL** — 50–90% зелёных, ЛИБО есть красный, попадающий в явный пункт AC.
- **FAIL** — < 50% зелёных, либо названные в тикете файлы не созданы, либо воркер вышел на
  эскалацию (по правилу маршрутизации второй заход Luna запрещён).

Классификацию «имя vs поведение» делаю по тексту тикета: если символ/поле названы в тикете
дословно — расхождение считается поведенческим (воркер обязан был назвать так же).

Записываю по каждому прогону: число ходов, число вызовов инструментов, `cost_usd` из
`turn_usage`, wall-clock, размер диффа.

**Чего замер НЕ доказывает и о чём пишу в ограничениях:** оба тикета — из одной задачи (#186) и
одной предметной области (квота), оба сформулированы после двух раундов Codex-ревью плана,
то есть это благоприятный край корпуса, а не типичный тикет. N=1 на ячейку.

## Поправки к стенду (дописаны 12.08 06:2x, ПОСЛЕ первой попытки, до снятия чисел)

Две правки. Обе меняют СТЕНД, ни одна не трогает критерии PASS/PARTIAL/FAIL выше.

**1. Первая попытка недействительна: worktree в общем репозитории показывает ответ.**
`spawn_worker(repo_path=/home/kesha/orchestra)` даёт воркеру worktree с ОБЩИМ хранилищем
объектов, поэтому `git show <sha>:<файл>` достаёт любой коммит `main`, включая тот, где лежит
искомая реализация. Оба воркера (`replay-t1`, `replay-t3`) нашли ответ на первом же ходу, не
получив ни номера задачи, ни SHA: `git log --all --oneline -- app/quota_runway.py`,
затем `git show 90af8a74:app/quota_runway.py`; второй дошёл до
`git show deed3974:tests/test_quota_alert_state.py` — то есть до самого файла-оракула.
Дословные строки: `docs/tasks/210/contaminated-run-evidence.txt`. Прогоны остановлены и убиты,
их расход ($0.021 + $0.032) записан в бюджет.

Стенд перестроен: `git clone --no-local --single-branch` в `/tmp/t210/repo-t1` и
`/tmp/t210/repo-t3`. `--no-local` обязателен — локальный клон копирует хранилище объектов
целиком, и `git cat-file -e e9a93b00` в нём проходит. Проверено после перестройки: оба
искомых коммита недостижимы, `app/quota_runway.py` в базе A отсутствует, `quota_alert_state`
в `app/db.py` базы B отсутствует.

**2. `docs/tasks/186/research.md` в базе есть, и это НЕ утечка ответа.**
Ресёрч смержен раньше выбранных баз, поэтому воркер его видит; в базе B видит и `plan.md`.
Убирать не стал, и это осознанный выбор: в самой проверяемой схеме ресёрч и план — смерженные
артефакты, они лежат в репозитории до того, как исполнитель начнёт работу. Условие
«исполнителю доступны письменные артефакты, но не контекст сильной модели» и есть проверяемая
схема. Прогон A видит `research.md`, прогон B — `research.md` и `plan.md`.
Формулировка предрегистрации «ни ресёрча» описывала более строгий вариант; фактически
измеряется более благоприятный для H1, и вывод должен читаться с этой поправкой.

**3. Уточняющий вопрос исполнителя разрешён, ответ по существу — нет.** `replay-a` спросил
форму полей и значение `MIN_WORK_HOURS_FOR_PACE` (в тикете оно упомянуто, но не задано).
Ответ: «текст тикета — вся спецификация, решай сам и запиши допущение». Сам факт вопроса
записывается как цена схемы (round-trip к оркестратору), содержание ответа в реализацию не
попадает.
