# #140 — аудит себя: совершаем ли МЫ ошибки, за которые ругают агентную разработку

**Дата:** 07.08.2026 · **Автор:** Opus 5 · **Внешнего рецензента не было** (квота Codex до 08.08 07:53)

## Вопрос

Повод — тезисы практика о четырёх дефектах агентной разработки: (1) имя на месте, содержание
подменено; (2) актор и критик из одной модели; (3) тесты пишет тот же агент под ту же неверную
модель мира; (4) дифф больше ~300 строк не ревьюится. Проверяется НЕ текст повода, а НАШ
репозиторий: совпадают ли DONE-отчёты агентов с тем, что лежит в `main`.

- **Контекст:** 109 коммитов в `main` с 04.08 по 07.08.2026 (`git log main --since=2026-08-04 --no-merges | wc -l`).
- **Что проверяется:** утверждения из отчётов, каждое — командой против текущего кода/БД/тестов.
- **База сравнения:** заявленное состояние против фактического.
- **Измеримый исход:** доля ОПРОВЕРГНУТЫХ утверждений и число найденных подделок с `файл:строка`.

## Метод и его граница
