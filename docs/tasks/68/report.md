# #68 — цвет подписи «‹кто› → ‹кому›» доезжает при позднем списке агентов

## Что было

`addChatEntry` красила подпись и левую рамку входящего `[from:X]` сообщения инлайном из
`agentColors[X]` с фолбэком `#64748b`. `agentColors` заполняется только в `renderAgentList`
из ответа `/api/sessions`. Отрисовалась история раньше списка → серый цвет впечатан в узел
навсегда, до полной перерисовки чата. #64 сдвинул отрисовку чата на ~340 мс раньше и
расширил это окно.

## Что сделано (`app/static/js/app.js`)

- `_senderColor(sender)` — единственный владелец соответствия «агент → цвет» (та же логика,
  что была инлайном: точное имя → префиксное совпадение ключа → серый).
- `_repaintSenderColors()` — проходит по `#chat [data-from]` и переставляет цвет подписи
  (`.chat-from-label`) и левой рамки.
- Узел помечается `data-from="<sender>"`, подпись — классом `chat-from-label`.
- `renderAgentList` считает `colorsChanged` (цвет реально новый, а не тот же самый) и
  зовёт репейнт только при изменении — на опросе раз в 3 с лишней работы нет.

Второй копии словаря цветов не заведено: `agentColors` остаётся единственным источником,
обе новые функции читают его.
