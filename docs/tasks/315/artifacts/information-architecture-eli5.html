#315 · простое объяснение

Одна кладовая. Разные коробки.

Задачи, доказательства и знания должны находиться по одному адресу — но жить по разным правилам.

Что решаем Не «куда сложить JSON», а кто является правдой, кто только быстрым экраном, и что делать при отставании.
01

Сейчас: пять комнат не разговаривают

Один и тот же номер может жить в нескольких местах. Индекс может показывать вчерашнее.

дублированная идентичностьсвязь может быть старой
1 фактможет быть в task, Markdown, логе и индексе.
0 HEADтекущий поиск не знает, до какого коммита он дошёл.
Не «нет»пустой индекс может означать только «ещё не догнал».
02

Цель: один адрес, три скорости

Кладовая хранит правду. Дашборд и каталог ускоряют чтение, но не могут переписать правду.

канон → проекцияотставание → прямое чтение канона
Один IDURI ведёт к типизированной записи.
Три headвидно, кто отстал: canonical, projection, indexed.
Одна правдакаталог и дашборд только показывают её быстрее.
03

Одна задача: путь от запроса до факта

01

Создать

Задача получает stable UUID и проектный #N.

02

Доказать

Воркер пишет evidence в docs/tasks.

03

Смержить

Merge receipt связывает commit, задачу и evidence.

04

Поднять

Только evidence-backed запись становится fact.

05

Искать

current, rejected и as-of не смешиваются.

04

Где аналогия ломается

SQLite — не склад

Во время миграции он всё ещё владеет быстрым operational runtime. Но новая истина не должна жить только там.

Git — не поисковик

Git хранит историю и доказательства. Для быстрых запросов нужны проекции.

Search — не судья

FTS/vector помогают найти карточку. Они не решают, какой факт текущий.

05

Три решения перед реализацией

Выберите вариант — карточки просто показывают выбранный default локально, без сети.

Решение 1

Как назвать задачу?

Стабильный UUID — для системы. Проектный #N — для человека и старых ссылок.

Default: UUID + project #N
Решение 2

Где секреты?

За пределами обычного Git, prompt и индексов. Ссылка может остаться, значение — нет.

Default: private store
Решение 3

Кто меняет факт?

Доказательство и явный supersedes. Спорный случай проходит человеческий conflict gate.

Default: evidence + human gate
Выбрано: UUID + project #N · Secrets outside Git/index · Evidence supersedes + human gate
