Самый полезный внешний шаблон — Cline, но не из-за текста prompt.

Он защищает новейший typed user turn, если тот идёт после index 0, сохраняет 20k свежих токенов, не разрывает tool_use/tool_result и вычисляет Files из событий. При ручной повторной compact он возвращается к canonical transcript, чтобы не жевать summary от summary.

Какие структуры prompt повторяются
Codex: progress/decisions → constraints/preferences → remaining → critical references. OpenHands: user context → exact task tracking → completed/pending/current state → code/tests/changes/deps/VCS. Cline: one-sentence goal → done/in-progress/blocked → highlights → immediate next → files read/edited. Anthropic cookbook: intent → completed → errors & corrections → active → pending → key references.
Что они выкидывают
Рутинные/старые tool outputs, повторения, superseded file windows, pleasantries, неактуальные детали прошлой summary. Но зрелые реализации оставляют маркер удаления или сырой хвост, чтобы «чистота» не стала молчаливой амнезией.
Что говорят провайдеры
Anthropic рекомендует точные IDs/paths/values/errors, приоритет corrections/errors/active work и несуммаризованный хвост после cursor. OpenAI Responses использует opaque compaction item и требует передавать canonical compacted window целиком, не редактируя его вручную.
Академический вывод
Recursive summarization масштабирует длину, но plain merging усиливает hallucination. MemGPT предлагает hot/cold tiers; ReSum — reset к goal + state; ACON учит guideline на парах «full succeeds / compact fails». Для нас это означает: оптимизировать правила по нашему failure ledger и периодически re-ground к источнику.
