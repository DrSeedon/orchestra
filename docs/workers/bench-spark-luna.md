# bench-spark-luna

- В слепом retrospective-бенчмарке `git clone --no-local` и закрытый parent repo доказывают только отсутствие shared-object leak. Доступная сеть или остальной `$HOME` оставляют ответ физически достижимым; отсутствие `web_search`/сетевых команд доказывает неиспользование, но не недостижимость.
- Перед включением модели в routing проверять не только наличие alias/quota lane, но и путь завершения usage accounting: `price=None` может поднять исключение после ответа модели, до `turn_end`, и сделать формально доступный route непригодным.
- Задачи трекера для Orchestra создавать с точным `project="/home/kesha/orchestra"`: короткое `"orchestra"` — другой скоуп, невидимый в рабочем списке проекта.
- Prompt-модули, которые читают агенты всех проектов, — shared runtime, даже если diff только текстовый. Для implementation diff нужен Codex-review либо явный waiver оркестратора; «это не код» не основание для пропуска.
