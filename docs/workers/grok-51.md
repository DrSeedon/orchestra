# grok-51

## Playwright: пустой контейнер ≠ видимый

`to_be_visible()` требует ненулевой bounding box. Пустой flex без padding (`#orch-tabs`) — 0×0, Playwright считает его невидимым. Тест «контейнер виден» зеленеет только когда живой API уже нарисовал детей; в полном прогоне тот же запрос тормозит или падает в `catch {}` — и тест краснеет, хотя в одиночку зелёный. Это не order-dependence.

Чинить: пинить ответ API и ассертить **свой** дочерний узел, либо `to_be_attached()` если проверяешь сам шаблон. Сосед уже так сделал для `#usage-bar`.

Мутация такого теста — ПРЕДУСЛОВИЕ (пустой ответ API), не ассерт: сломанный ассерт не доказывает, что тест вошёл в тело.

Замер: #197, `test_header_has_orch_tabs`.
