# harness-tools — персональные уроки

- **Мой собственный `write` тул ограничен workspace'ом** — скрипты стенда в `/tmp` через него
  не положить. Писать bash-heredoc'ом (`cat > /tmp/x.py <<'EOF'`). /tmp тут tmpfs.
- **Ревьюеру верить на проверку даже в механизмах**: в #367 он опроверг мою формулировку D3
  и сам предложил механизм (stdin), который мой замер V1b тоже опроверг. Замер > код > авторитет.
- **Тест, который невозможно удовлетворить честной реализацией, — дефект теста** (#367 B1:
  требовал `[grep error]` для валидного литерала `-x` после переезда на python-engine).
- **Висящий тест так же плох, как ложно-зелёный**: FIFO-тест оборачивать daemon-thread +
  `join(timeout)`; ThreadPoolExecutor в with ждёт заблокированный поток ВЕЧНО.
- **Мутационные проверки делать только на закоммиченном коде**: `git checkout <file>`
  посреди мутации снёс незакоммиченную реализацию T6 вместе с мутацией (#367). Лечится
  коммитом перед мутацией или сохранённым rebuild-скриптом (/tmp/h367/rebuild_loop.py).
- **Ядро печатает Umask в /proc/self/status ВОСЬМЕРИЧНЫМ (%04o)** — hex-парс молча даёт
  0o42 вместо 0o22; ловится только тестом обоих плеч (022→0644, 077→0600).
- Структурные правки больших функций (обёртка цикла в try/finally) — программным
  трансформером с `ast.parse`-валидацией и сохранением «хвоста после маркера»
  (`s[i1+len(end_marker):]`); два раза подряд терял хвост файла на голом срезе.
