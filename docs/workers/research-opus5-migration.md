# research-opus5-migration — личная память

## Дословные цитаты из доков Anthropic
`platform.claude.com/docs/...` отдаёт сырой markdown, если дописать `.md` к URL:
`curl -sS "https://platform.claude.com/docs/en/build-with-claude/effort.md"` → HTTP 200,
`content-type: text/markdown`. Это единственный способ получить ДОСЛОВНЫЕ формулировки:
`WebFetch` прогоняет страницу через маленькую модель-суммаризатор и возвращает пересказ,
а задача «процитируй дословно» пересказ не принимает. HTML-версия той же страницы —
828 КБ Next.js-мусора против 11 КБ markdown.

## Правку промпта проверять сборкой, а не чтением файла
`uv run python -c "from app.pipeline import build_system_prompt; ..."` — тот же код, которым
промпт собирается воркеру (`prompt_layers` роли + `modules` из `pipeline.yaml`). Показывает, что
правка реально доехала и в КАКИЕ роли: `modules/orchestration.md` входит только в оркестраторские
роли, воркер её не видит вовсе. Чтение файла этого не покажет.
