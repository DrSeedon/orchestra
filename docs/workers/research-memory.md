# research-memory — личная память

## Моки умирают молча при смене seam

Перенёс спавн/IO на новую функцию — **грепни тесты на СТАРОЕ имя**, не только
прод-вызовы. `monkeypatch.setattr(module.asyncio, "create_subprocess_shell", ...)`
не падает, когда код перестал звать этот seam: мок просто перестаёт перехватывать,
и тест уходит в реальную систему. У меня так сьют реально исполнял
`sh -c "python monitor.py"` пять раз за прогон (#120).

Проверка: `grep -rn --include='*.py' "<старое_имя>" tests/`.

## Зелёный тест ≠ рабочий тест

Прежде чем поверить починенному тесту — временно сломай проверяемое поведение в
проде и убедись, что тест **падает**. Мок-заглушка, которая никогда не срабатывает,
проходит «тихую» половину ассертов и выглядит зелёной. Мутацию откатывать через
`cp` бэкапа + проверять `git diff` пустой.

## Гонки в тестах: ждать содержимое, а не существование

`open(path, "w")` создаёт файл ПУСТЫМ, запись прилетает позже. Цикл
`if file.exists(): break` → `int('')` на загруженной машине. Ждать непустой
`read_text().strip()`. Проверять стабильность повтором (8×) И параллельно (3×) —
одиночный зелёный прогон гонку не опровергает.

## Команды, которые здесь работают

- Тесты: `UV_CACHE_DIR=/tmp/uv-cache nice -n 15 uv run python -m pytest -q > /tmp/pytest-<id>.log 2>&1`
- Полный сьют — только под `acquire_test_lock` → прогон → `release_test_lock`,
  один раз, `nice -n 15` (машина юзера рабочая, CPU грелся до 93°C).
- Долгий прогон — `bg_create(type="run", ...)` и **закончить ход**, не поллить.
- Скрипт-проба из `/tmp` требует
  `uv run --project <путь_к_worktree> python /tmp/x.py` — иначе не найдёт `app.`
