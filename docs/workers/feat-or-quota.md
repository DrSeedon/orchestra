
## Уроки #368 (22.08)

- Глобальный флаг здоровья (`_last_error`) отравляется навсегда одним транзиентным сбоем
  (чужой тест без init_db) → успешная операция обязана сбрасывать флаг (self-heal), иначе
  «unhealthy» переживает починку. Поймано только комбинированным прогоном тестов — по одному
  файлу зелено.
- Мутационная проверка вскрыла: сиды-фикстуры с NULL/нейтральными значениями переживают
  мутанта «фильтруй по статусу». Сиды должны нести ЯВНЫЕ РАЗЛИЧНЫЕ значения (200+429), тогда
  любой фильтр ломает равенство.
- Фикстура «ускорить бэкофф» (BACKOFF_BASE→0.001) убивает ассерт на рост экспоненты: диапазоны
  соседних задержек перекрываются. Если sleep подменён и никто реально не ждёт — используй
  настоящую константу.
- Красный от ImportError отвечает на «исполняется ли», не на «сторожит ли»: для каждого AC
  спрашивай отдельно, может ли тест быть зелёным на неверном коде, ДО реализации.
