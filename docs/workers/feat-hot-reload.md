# feat-hot-reload — личная память

## Реконструкция ходов агентов из `data/orchestra.db`

Понадобится каждый раз, когда нужно «сколько ходов шло одновременно / как долго идёт ход».

Наивная пара «`user_message` → следующий `turn_usage` той же сессии» **НЕВЕРНА и завышает
одновременность на 45%**. `session.py:887` (сообщение в очередь при компакте) и
`session.py:891` (вклинивание в идущий ход) оба пишут `user_message` и делают `return`, хода
не начиная. На 7 сутках это 533 лишних окна из 2 020.

Правильно: **одно окно на строку `turn_usage`**; началом брать самое раннее `user_message`
после ПРЕДЫДУЩЕГО `turn_usage` этой же сессии. Даёт 1 507 окон, среднюю одновременность
1.50 в рабочие часы (UTC 04–13), медиану хода 89 с, p90 705 с.

Чего в этих данных нет вовсе: убитых и зависших ходов — у них нет строки `turn_usage`.
Любой вывод по окнам смещён в сторону успешных ходов, это надо писать вслух.

## Фактические рестарты Orchestra

Единственный надёжный след — `logs` где `type='user_message'` И
`content LIKE '[system] Orchestra server restarted%'` (`manager.py:1824`). **Обязательно
фильтровать по `type`**: без него в выборку попадают tool/tool_result строки агентов,
которые эту же фразу процитировали (ловил на себе — 3 фальшивых рестарта из 16).

След остаётся только у рестартов, заставших кого-то в `running`. Рестарт, никого не
заставший, невидим — значит любая метрика «время до ближайшего рестарта» это ВЕРХНЯЯ оценка.

## Проверка своей правки в `app/**.py` без рестарта

Живой сервер поднят из ГЛАВНОГО чекаута `/home/kesha/orchestra`, worktree на него не влияет.
Проверять отдельным процессом: `uv run python <скрипт>` с `sys.path.insert(0, <worktree>)` и
`os.chdir(<worktree>)`. Первый `uv run` в свежем worktree создаёт свой `.venv` (~1 мин),
дальше быстро.

## Мутация в Python: `touch` обязателен

`cp F F.bak` → мутация → `os.utime(F)` → `sleep 1.1` → `os.utime(F)` → `importlib.invalidate_caches()`.
Без задержки CPython держит `__pycache__` по паре (mtime, size) с секундной гранулярностью, и
правка той же длины в ту же секунду не подхватывается. Откат — `mv F.bak F` + `utime`, потом
ОБЯЗАТЕЛЬНО контрольный прогон: он отличает «мутация откачена» от «мутант ещё исполняется».
