## Границы выводов

- Виртуальные API-доллары в telemetry — расчётная единица, не реальный subscription debit; это явно разделено в `docs/tasks/312/measurements.md`, раздел `Subscription consumption and coverage`.
- Observation не превращена в causality: regression «calls→cost» не доказывает, что prompt-rule фактически уберёт calls без компенсации другой работой (`docs/tasks/345/call-to-dollar.md`, `Пробелы`).
- Process/session counts не используются как concurrency: exact active turns берутся из native intervals (`docs/tasks/255/measurements.md`, `Coverage and boundaries`).
- Зелёный test output не считается достаточным сам по себе: для high-risk delivery/restart использовались frozen RED oracles, negative controls и mutations (`docs/tasks/333/report.md`; `docs/tasks/379/report.md`).
