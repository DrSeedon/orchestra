## Ветка фичи

- [ ] Ответвлена от согласованной базы (`feat/{feature}` или как договорились)
- [ ] Базу уточнил у PM/юзера, не выбирал сам

## Этапы (TDD)

На каждый сценарий из TDD_PLAN:

- [ ] **Тест** — написан, падает (red)
- [ ] **Код** — минимальный, тест зелёный (green)
- [ ] **Рефактор** — SOLID/DRY/KISS, без дублирования
- [ ] **Ревью** — код-ревью через субагента/codex
- [ ] **Правки** — замечания ревью закрыты

## Тесты

- **Узкие** (по фиче): `uv run pytest tests/<файлы фичи> -q -p no:cacheprovider`
- **Полный сьют** (регресс): гонять ПОСЛЕДОВАТЕЛЬНО, БЕЗ `-n` (SQLite-лок)

- [ ] Узкие тесты зелёные
- [ ] Полный сьют зелёный, регресса нет
