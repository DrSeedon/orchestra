# Sprint Dashboard

Дашборд PM-главы. Один спринт = набор фич. Обновляй статусы по мере работы.

## Фичи

| Фича | Статус | Приоритет | Заметки |
|---|---|---|---|
| | backlog / в работе / на приёмке / готово | P0 / P1 / P2 | |

## Чеклист по каждой фиче

Заполни блок на КАЖДУЮ фичу из таблицы перед запуском PM-фичи.

### <название фичи>

- [ ] **Цель / ценность** — зачем фича, какую боль закрывает, кому
- [ ] **Новая / продолжение** — с нуля или развитие существующего; если продолжение — что уже есть
- [ ] **Связи** — зависимости от других фич, общие модули, потенциальные конфликты
- [ ] **Срочность** — дедлайн, блокирует ли других, цена ожидания
- [ ] **Критерий готовности** — что значит «фича сделана» (наблюдаемый результат)
- [ ] **Риски** — технические/продуктовые неизвестные, что может пойти не так

## Акт приёмки фич

Фича переходит в «готово» только после явной приёмки.

- [ ] Критерий готовности выполнен (проверено наблюдаемо, не на словах)
- [ ] Тесты зелёные, регресса нет
- [ ] Ветка фичи влита в целевую (или PR открыт и одобрен)
- [ ] Юзер подтвердил приёмку
